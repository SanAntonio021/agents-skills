# 论文原文与笔记核对

用于用户提出的具体技术疑问或已授权的笔记修订。只读取与问题有关的正文、图表、公式和必要补充材料；日常整篇总结继续使用现有 Zotero 工作流。

## 核对方式

- 先定位原文，再判断笔记。图中连接顺序、上下标、公式、表格合并单元格或文本提取有歧义时，查看对应页面图像。按需用 PDF 工具；需要提取原图时使用本技能的 `scripts/extract_paper_images.py`，只检查相关图表，不强制全篇抽图。
- 给出页码、章节或原始图表/公式编号。原文有冲突就分别列出；材料未提供时说明当前能确认到哪里，避免补出原因。
- 结合论文类型、方法、实验设计和作者所述局限解释适用范围，保留负结果与谨慎措辞。已有 Markdown 抽取（包括 Paperzilla 输出）可作为检索输入；排版或语义疑点回到原 PDF 核对。
- 保留数值对应的对象、属性、单位、条件，以及“测得、得到、设定、可望”等动作和限定。多级系统写清器件级别、连接顺序与输入/输出位置；不同位置的参数分句说明。
- 区分作者陈述、图表显示与自行推导。只有解释当前疑问需要时才补充推导，并写清计算条件。下限或上限不能当作精确值，例如“优于 18 dB”本身不能证明未达到 20 dB。
- 核对公式时说明用途、相关变量和单位、输入与输出；核对图表时保留原编号、坐标、图例及比较条件。按当前问题选择内容，不默认抄整表或逐图解说。

## 工程论文的常见口径

按论文领域选用，其他领域沿用相同的对象与条件核对方法：

- 速率区分单通道与聚合、线速率与净信息速率；编码区分帧头与载荷、已实现与计划实现，BER 区分 pre-FEC 与 post-FEC。
- 带宽区分模拟、信号及占用带宽；SNR/OSNR、EVM 保留定义、带宽和测量位置。采样帧数只归到原文明确对应的测量，不能从 EVM 测试借给 BER。
- 距离区分无线、光纤、总链路与预算外推；离线计算、实时处理、仿真与实测分别说明。
- 器件参数保留术语本义，如抽头数与滤波器阶数；涉及 MIMO 或边带分离时，检查通道数、频域隔离、幅相误差或信道估计/均衡的实际作用。

## 交付与修订

先直接回答问题，再给必要定位和清楚的替换句。只要求核实时在对话中交付；明确要求修改或当前授权已覆盖时，读取最新笔记并通过现有 Zotero 插件做局部修订，核对保存结果，保留其他内容及用户改动。插件不可用时交付可用的修订句，并说明保存尚未完成。

核对不触发 A/B/C 分类、投稿通过声明或整篇重写。用户要求本地文件时才导出；付费模型重跑按实际授权执行，局部问题优先直接核对和修订。
