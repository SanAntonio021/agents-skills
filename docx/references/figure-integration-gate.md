# 图片引用与图题检查

导出前核对当前采用的图片、图号、题注与正文引用，不改变科学含义或静默换图。

- 复用用户指定文件及项目已有图清单。已有清单时核对路径、状态、SHA-256、尺寸、数量和顺序；不凭文件名、修改时间或 `final/` 目录猜版本。
- 普通单图、用户明确提供的图片不必新增确认清单。多个候选无法确定当前采用版本时，只询问该项；其余内容继续处理。
- 图号、题注、替代文字与正文交叉引用对应；图题可概括图片内容，不强制与章节标题逐字相同。不得残留候选路径、待插图说明或“图建议”等占位内容。
- 整稿生成时，应编号的图表题注及正文引用按[编号与交叉引用](numbering-references.md)建立 `SEQ`、稳定书签和 `REF`；无编号对象保持不编号。局部编辑只刷新全文已有相关内部域，不擅自转换无关纯文本引用。需要转换或调整编号时保存明确映射，重复/缺失目标及引用区间端点未解决时不得猜配。
- 从实际题注确认对象身份，不以“图片后一段”猜题注；图片与题注可能同段，同一图片关系也可能被复用。图中科学含义与正文的关系由智能体检查，修改图题时查看实际图片，仅作有依据的修改，不补造科学结论。

已有项目最终清单时可使用：

```powershell
python <skill-dir>/scripts/validate_figure_references.py `
  --manifest <project-final-manifest.json> --project-root <project-root> --json
```

该脚本验证既有严格清单的路径、状态、哈希、尺寸、图号与引用数量；不是所有 Word 任务的必建状态机，也不证明 Word 域已原生刷新并保存。清单变更使用本次真实授权，保留历史记录，重新检查受影响引用。新整稿及图表布局修改仍需按成品检查要求渲染；单纯域刷新不新增渲染要求。
