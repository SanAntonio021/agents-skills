# 实验指标表

主表逐次记录：第一行表头，第二行单位，第三行起是对应观测。没有单位的格子留空；一个格子只放一个参数，单位不重复写进表头和数值。同次采集的不同通道共用观测序号、分行记录，失败行保留，缺失数值留空，实际零保留。

表头应让人看得出：哪个设备或位置、什么量、是设定值还是测得的值。涉及多个通道或处理阶段时，注明具体通道或阶段；设备回读与实测不同，计算结果按实际来源命名。

| 含糊写法 | 清楚的表头 | 第二行单位 |
|---|---|---|
| 幅度 | AWG CH1 输出幅度设定值 | Vpp |
| 功率 | 信号源输出功率设定值 | dBm |
| 功率 | 发射端射频输出功率实测值 | dBm |
| 幅度 | 示波器 C1 实测峰峰值 | Vpp |
| BER | 译码前 BER | |

这些只是命名示例，不是每个实验必填的列。AWG 的实际单位依设备接口或资料确认，不把所有幅度都假定为 Vpp。采集带内积分功率应注明通道和积分范围，不能用它冒充发射端 RF 实测功率。

两行表头示例（下方数值仅为格式演示）：

```csv
观测序号,通道,AWG CH1 输出幅度设定值,示波器 C1 实测峰峰值,译码前 BER,状态
,,Vpp,Vpp,,
1,C1,0.125,0.1234,2.30e-03,成功
2,C1,0.125,,,采集失败
```

设定值保留实际设置精度；测量显示精度按仪器分辨率或实验需要确定。不要统一四舍五入成两位小数。未指定精度时保留数值；末尾零需要显式格式或原始文本。BER 默认三位有效数字科学计数，实际零写 0；完整数值另行保存，不从显示表反推精确数据。程序参数见 [指标、精度和记录](standard.md#3-指标精度和记录)。

主表不自动汇总均值、标准差或其他跨观测统计。统计方法须事先设计，或拿到逐次结果后另行讨论确定。整轮总览也按本轮任务再设计指标、坐标、布局与图数，复用公共绘图程序；单次采集已有的波形、频谱和解调图组不受此影响。
