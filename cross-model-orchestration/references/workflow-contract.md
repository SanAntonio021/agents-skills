# 工作流契约

## 调用串行约束

计划复核、执行和返工各阶段最多启动一次后台 Codex 任务（`--background --fresh --write`）。
该任务返回终态前，只允许轮询 `status`；不得再次启动任务、重发 prompt 或启动其他
Codex 工作链。认证、权限、sandbox、timeout、额度或 runtime 失败直接输出
`CODEX_FAILURE_REPORT`，不重试。

**无定向续接**：本 Skill 中 `--resume`/`--resume-last` 一律不使用，各阶段均 `--fresh`。
正文来源是 job JSON 的 `rendered`（完整响应体），不以 `.log` 作为兜底。

## Shell 传输格式

后台任务提示词（用于复核、执行、返工）以单行字符串传入 companion：

- 使用”字段名=值；”分隔各字段；
- 完整保留目标、范围、证据、计划、交付物、验收标准、安全边界和输出契约；
- 字符串中不得出现字面 CR/LF；
- Windows 任务参数内部不使用 XML 结束标签或 `C:/` 绝对路径；优先写相对 cwd 的路径，
  必须写绝对路径时使用反斜杠；
- 不用临时文件、here-doc、管道、重定向或命令替换；
- 三次调用（复核、执行、返工）遵守同一规则。

单行示例：

```text
模式=只读复核，不修改文件，不执行计划；目标=...；范围=...；证据=...；计划=...；交付物=...；验收标准=...；安全边界=...；输出契约=严格按 PLAN_REVIEW 输出
```

## 计划复核提示词

启动后台任务时使用以下结构（带 `--background --fresh --write`）。明确写出
“只读复核，不修改文件，不执行计划”。

后台任务完成后通过 `result <jobId>` 取 `rendered` 字段作为复核输出。
Claude 应在启动前为复核范围内每个普通文件记录相对路径、字节数和 SHA256，排除
`.git` 内部元数据；Git 项目再额外记录 Git 状态。任务完成后逐项比较，不能只看
`git status`。只有没有任何变化时才接受 `PLAN_REVIEW`。

```text
只读复核，不修改文件，不执行计划。

任务目标：<目标>
范围与排除项：<范围>
输入与证据：<材料>
Claude 的计划：<步骤>
交付物：<交付物>
验收标准：<逐条标准>
安全边界：<限制>

请检查完整性、可执行性、证据边界、遗漏风险和验收标准。严格按 PLAN_REVIEW 输出。
```

## PLAN_REVIEW

```text
PLAN_REVIEW
结论：通过 | 需修改 | 实质分歧
已确认事项：
- ...
问题与理由：
- <问题；理由；证据或待核事实>
必须修改：
- ...
剩余风险：
- ...
```

`通过` 仍需写剩余风险；没有问题时写“无”。`需修改` 必须给可执行修改项。
涉及方向、价值判断或证据无法消除的冲突时用 `实质分歧`。

## 执行提示词

计划通过后，以 `--background --fresh --write` 启动新后台任务执行：

```text
按已通过的最终计划执行任务。你可以在授权范围内读取和修改文件、运行命令、
生成交付物。不要扩大范围。遇到删除、重置、权限变更、付费、对外发送、硬件
操作、覆盖、会丢失既有内容的整文件替换，或计划外方向选择时停下说明，
不要自行决定。计划已经授权的局部修改不需要重复询问。

最终计划：<计划>
允许修改范围：<路径或对象>
验收标准：<逐条标准>

完成时报告实际修改文件、实际运行命令、逐条验收证据、失败项和剩余风险。
```

## 返工提示词

返工以 `--background --fresh --write` 启动新任务（无定向续接，见串行约束）：

```text
Claude 验收未通过。请只修复以下问题，不扩大范围；修复后重新运行必要验证。

问题：
- <文件或对象；观察到的事实；为什么不通过；通过判据>

请报告修改、验证证据和仍未解决的事项。
```

## DISAGREEMENT_REPORT

只整理双方已有判断与证据，不推荐或代选方案，不新增未经双方评估的折中方案。
输出后暂停，等待用户裁决。

```text
# 需要用户裁决

## 已达成共识
- ...

## Claude 的判断
- 结论：...
- 理由：...
- 证据：...

## Codex 的判断
- 结论：...
- 理由：...
- 证据：...

## 实质分歧
- ...

## 需要决定
- <一个明确问题及各选项影响>
```

## CODEX_FAILURE_REPORT

本报告只用于已经通过宿主环境检查，并已尝试启动 Plugin companion 或 Agent job 后
发生的认证、权限、sandbox、timeout、额度或 runtime 失败。启动协作任务前发现当前
宿主不是 Claude Code CLI，不属于调用失败，不使用本报告。

```text
# Codex 协作已暂停

- 失败阶段：计划复核 | 执行 | 返工
- 关键错误：<最短决定性错误>
- job ID：<已知 ID；未知则写未知>
- expectedThreadId：<已记录 ID；未记录则写未知>
- candidateThreadId：<当前候选 ID；查不到则写未知>
- 已完成内容：<文件、结果或无>
- 未完成内容：<范围>
- 恢复条件：<登录、额度、重试或可靠续接条件>
```

输出后停止，不由 Claude 继续执行。

认证、权限、sandbox、timeout、额度或 runtime 错误都属于调用失败，不属于普通
验收失败。出现这些错误后不得重试、修订计划绕过、另开 thread 或转由 Claude
执行；直接按本报告暂停。
