# Vivado FPGA 开发入口

本技能负责路由与任务交接，专业方法由专项技能维护。用户只需描述结果，不需要列出技能名。

## 开始与范围

读取目标项目 README、AGENTS 和当前相关代码、脚本或报告，确定已有工程模式、工具版本、输入输出与授权。复用已有决定；只有影响接口、科学含义或执行范围且无法从材料核实的事项才提问。

区分解释审查、生成代码或脚本、执行仿真、综合实现和硬件操作。加载技能不新增授权；只生成脚本时不得自动执行，不因工程检查自动启动构建或硬件连接。已授权的必要验证继续完成，不逐阶段重复请示。项目的硬件禁令优先于专项示例。

## 按需路由

| 当前任务 | 主技能与配套 |
| --- | --- |
| 编写、修改、审查 RTL，设计接口与数据通路 | [fpga-rtl](../fpga-rtl/SKILL.md)；资源推断需要时加载综合技能 |
| 自检测试、行为仿真及失败定位 | 功能场景由 [fpga-rtl](../fpga-rtl/SKILL.md) 负责；工具运行由 [vivado-sim](../vivado-sim/SKILL.md) 负责 |
| Tcl 生成、审查或已授权批处理 | [vivado-tcl](../vivado-tcl/SKILL.md) |
| XDC、时钟、I/O、物理约束、CDC 约束 | [vivado-constraints](../vivado-constraints/SKILL.md)；CDC 电路设计同时加载 RTL 技能 |
| RAM/DSP/FSM 推断、综合策略与报告 | [vivado-synth](../vivado-synth/SKILL.md) |
| 解读时序、资源、QoR、方法学报告 | [vivado-analysis](../vivado-analysis/SKILL.md) |
| 布局布线、物理优化 | [vivado-impl](../vivado-impl/SKILL.md) |
| 系统性时序收敛 | [vivado-timing-closure](../vivado-timing-closure/SKILL.md)，按实际问题补充分析、约束或实现技能 |

只读取当前需要的技能及其相关资料，不一次加载整套。混合任务保持同一上下文，先完成依赖再进入下一步；专项间已经交换的信息不重新询问。可直接点名专项使用，专项不必回调本入口，避免循环。

## 验证与交付

将源文件版本、接口要求、授权范围和验收条件随任务传递，不另建固定流程文件。由当前主技能选择最小必要检查，区分代码审查、功能仿真、综合、实现时序与硬件实测；未执行的阶段不标为通过。

报告完成内容、实际验证和剩余限制。专项缺失时说明具体缺项并继续可完成部分，不擅自安装依赖、调用其他模型或派发多代理开发。本入口不保存板卡地址、固定引脚或某项目的双口设计结论。
