# 论文终稿审校

本文件只用于 `mode=final_audit`。同时加载当前正文语言对应的规则，不自动加载另一语言。

## 审校顺序

1. 记录当前文件、范围和 SHA-256。
2. 建立“论点—证据—章节功能”表，核对摘要、正文、图表和结论。
3. 检查数字、单位、公式、变量、实验条件、比较基线和引用。
4. 检查缩写作用域、图注自解释、术语一致性和交叉引用。
5. 检查全文重复和 AI 气味；先保护科学限定，再处理句式。
6. 修改后重跑同一检查，报告最终文件的结果和哈希。

## 关键判断

- 摘要和结论可以复述核心结果，但需压缩并承担各自功能；整段复制判 `fail`。
- 结果段写观察事实，讨论或分析段解释原因和意义。两处只是换词重复时合并。
- 中位数、百分位数、CDF、置信区间等统计量要说明它们回答什么问题。
- 图注应说明对象、条件、面板、图例、单位和主要读法；图片存在时查看图片后判断。
- 固定间接否定、`fail to`、`neither...nor` 等结构不能仅因关键词命中就改写。
- 目标期刊格式只有在官方模板或作者指南核对后才能称通过。

## 工具边界

现有规范审计脚本可用于英文 Markdown 和单文件 LaTeX：

```text
python -X utf8 scripts/audit_manuscript_conventions.py --input <path> --format json
python -X utf8 scripts/audit_writing_memory.py --input <path>
```

退出码和候选项按脚本说明解释。脚本不能判断图片语义、事实真实性或引用是否真正支持论点；中文稿以人工表格审计为主。

## 失败条件

- 虚构或漂移的数字、公式、引用、设备和实验条件；
- 把计划、仿真或计算升级为实现或实测；
- 摘要、正文或结论存在无理由整段复制；
- 同一指标在图、表和正文中互相矛盾；
- 结论超过实验和证据的适用范围。
