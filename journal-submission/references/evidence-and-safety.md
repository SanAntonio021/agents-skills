# 证据与安全规则

## 证据记录

每个易变规则保存：

```text
url
accessed_on: YYYY-MM-DD
key_requirement: 完成当前操作所需的短摘要
applies_to: 期刊 / 文章类型 / 生命周期阶段 / 页面 / 租户
```

页面需要登录时，只记录稳定 URL 或页面名称，不保存 session 参数、cookie、token 或临时签名链接。

## 冲突处理

1. 当前页面与目标期刊指南不一致：暂停当前字段，记录两处原文和影响。
2. 出版商通用规则与目标期刊指南不一致：目标期刊指南优先，但先核对版本和文章类型。
3. 项目旧记录与当前官方页面不一致：保留历史；当前操作使用当前官方页面。
4. 社区经验与官方来源不一致：忽略社区规则。
5. Wiley Research Exchange 文档与 IEEE Atypon 租户页面不一致：视为不同租户，不跨租户推断。

## 最终提交与可选内容审查

最终 Submit 或返修 Submit 前核对当前稿件、作者、文件、声明、费用和投稿合规。内容审查按用户请求执行，`pre_submission_review` 缺失或 `not_run` 不自动阻止已准确授权的提交。有审查记录时：

- 声称 `pass` 必须有 `checked_at` 和非空、可定位的 `evidence`；
- 整稿版本未变则复用，小改检查受影响部分，方法、数据、主要结论或整体结构实质变化时评估整稿重审；
- `blocked` 及其问题保持原样，说明影响并处理相关事项；局部检查不代表整稿通过。

投稿合规检查发现明显内容问题时指出，不自动追加整套模拟审稿。用户要求的内容审查仍须完成，不能用材料齐备代替。

审查通过不等于提交授权。先备好准确摘要；已有当前稿件的提交授权可复用，需本人确认或签署的声明仍由用户处理。提交完成以系统确认页或邮件为准。

页面或阶段退出还必须同时满足：必填字段完成、机构匹配状态已记录为 `matched`、`manually_entered` 或 `not_listed`、当前页面要求的 proof/preview 已查看、阻断错误已清除。不存在的 proof 不要求查看。

## 不得猜填的实质选择

已有准确授权可复用，记录实际请求与选择；没有授权或发生实质变化时才询问。本人签署要求仍由用户完成。

- 最终提交或返修提交（最终 Submit、Complete、Approve、Confirm 或同义最终动作）；
- 作者增删、顺序和通信作者、投稿联系人及贡献角色；
- 推荐或回避审稿人；
- 伦理、利益冲突、数据、代码和重复投稿声明；
- OA、APC、版面费、超页费、彩色印刷费和付款责任；
- 版权许可、出版协议和第三方材料许可；
- 撤稿、转投或稿件转移。

确认后仍需回读页面值。回读失败时不记为完成。

## 凭据与身份

- 允许：浏览器现有登录会话、密码管理器自动填充。
- 禁止：读取密码框值、导出 cookie、保存 token、要求用户把密码发到聊天、把凭据写入 JSON/Markdown/日志。
- CAPTCHA 和 2FA 由用户完成。
- 作者库拒绝身份证号、手机号、学号、工号和个人经历。
- 测试只用合成作者、机构、邮箱和稿号。

## 文件安全与新鲜度

- 上传前记录路径、用途、大小和 SHA-256。
- 编译、压缩和逐页目检只对当时的输入快照有效。
- 输入在上传文件生成后发生变化，都要把相关 PDF、source 包和 Reviewer PDF 标为待重建；文件仍小于大小上限或肉眼看起来相同，不能替代重新构建和核验。
- 无输入快照时，`freshness_status` 只能记录为 `unknown`。
- 最终 `Submit` 前，重新生成受影响的文件，重新记录大小与 SHA-256，并回读页面中的文件名和版本。LaTeX source 包只在当前期刊指南或页面要求时生成。
- 提交确认后，已上传文件和 source 包作为不可变基线保存。若本地稿件后来变化，不把本地版本当成已提交版本，也不静默替换；在项目状态中记录差异，只有官方要求或用户确认返修/重投时才重新上传。
