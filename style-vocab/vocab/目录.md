# 词表目录

词表按“语言 + 文稿类型”选读。普通写作只读取本页指定的文风表；需要统一中英文术语时再读取 `术语.md`。`维护.md` 只在收录、迁移和检查规则维护时读取。

## 加载规则

| 语言 | 文稿类型 | 读取文件 |
|---|---|---|
| 中文 | 申报书 | `中文/通用.md` + `中文/申报书.md` |
| 中文 | 调研报告 | `中文/通用.md` + `中文/调研报告.md` |
| 中文 | 论文 | `中文/通用.md` + `中文/论文.md` |
| 中文 | 审稿回复 | `中文/通用.md` + `中文/审稿回复.md` |
| 中文 | 其他正式文稿 | `中文/通用.md` |
| 英文 | 论文 | `英文/通用.md` + `英文/论文.md` |
| 英文 | 审稿回复 | `英文/通用.md` + `英文/审稿回复.md` |
| 英文 | 其他正式文稿 | `英文/通用.md` |

同一“不建议”在通用表和任务表中同时出现时，以任务表为准。项目目录内存在 `术语.md` 时，项目术语优先于本目录的全局 `术语.md`。

## 文件格式

文风表固定为三列：

```markdown
| 不建议 | 建议 | 例外 |
|---|---|---|
```

术语表固定为两列：

```markdown
| 中文 | 英文 |
|---|---|
```

正式文稿中的命中只表示需要结合上下文复核；引用原文、参考文献、代码、URL、路径、LaTeX 命令和引用键不参与检查。
