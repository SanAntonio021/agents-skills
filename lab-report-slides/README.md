# 科研日报与组会 PPT

从会话、项目记录和真实图件整理导师日报或组会汇报，交付可编辑 PPTX。支持 Windows + Codex；采集器也支持 Claude Code 和 Cursor 会话，macOS/Linux 完整流程尚未验证。

## 开始使用

在 Windows 本机 Codex 中提供本页链接，说“请按页面流程完成安装”。执行者须读取 [安装与配置](references/installation.md)，连续完成依赖安装和实际样例验收。默认安装 `lab-report-slides`、`pptx`、`writing-router`、`style-vocab`；组会沿用 LibreOffice 兼容渲染，使用组会流程时还需安装 `libreoffice-runner`。日报默认不调用它。

安装后可以说：

- “生成今日汇报，只看这个实验项目，先列出科研进展让我选择。”
- “生成本周组会汇报，曲线在 results 目录；下一步只写已经确定的安排。”
- “把候选 1、3 做成 PPT，不写 2。使用项目里的汇报词表.md。”

日报默认从上一次已交付汇报的统计截止点接续到本次，覆盖中间未做汇报的日期。先盘点记录，给出第一页草稿和没上第一页的候选并问一次补充，再依次确认第一页、拟展开事项、素材与生成方式，三道确认完成后才制作；步骤见[主流程](SKILL.md#1-日报流程)。第一页每项先说为什么做、再说今天做了什么，不写参数和测量数值，也不写还没做的事；写法和案例见[第一页怎么写](references/chinese-style.md#第一页怎么写)。组会逐部分讨论确认，每部分正文写明项目名、直接前因、本次动作和结果或状态。日报默认只做轻量文件检查和一次 PowerPoint 原生打开/PNG 导出，快速检查遗漏、错图、不可读、裁切和严重遮挡；不做审美评判。

首次起草先确定证据支持的主张及理解它必需的信息，再生成页面文字；验证性质自然表达一次，核查过程和重复的未做事项说明默认留在记录，审校只作兜底。

素材默认复用现有原图、原表和文档截图，仅作必要裁切、放大或分页。审稿回复等长文稿可用原文PDF页面缩略展示完成情况；不因排版统一或可编辑性临时重画框图，确需新绘时按用户明确要求或同意处理。

## 模板与个人配置

首次未指定模板时选择内置样式或本地 `.pptx`／带样页 `.potx`，以后在同一项目沿用并可随时更换。原模板保留，适配与验收见 [本地模板流程](references/local-template.md)。

个人词表放在项目根目录 `汇报词表.md` 或指定其他文件，使用“不建议、建议、例外”三列。没有词表也能执行基础表达检查。模板、项目名、交付目录和词表保存在本机或项目中，不随公开技能分发；作者私人样稿不可用时跳过，不阻断制作。

日报只生成 PPTX 和 manifest，不调用 LibreOffice 或生成 PDF；随后通过 PowerPoint 原生打开并一次导出全部页面 PNG。文字是原生文本框，图件可独立移动和替换，图内数据仍是像素。组会同样只生成 PPTX，完整验收看 PowerPoint 原生导出的页面；PDF 交付仍仅按用户要求，HTML 仅显式请求时生成。

采集脚本不联网，但模型如何处理材料取决于所用服务和账号；本地采集不代表模型完全离线。原始会话、来源清单和私人图件不提交公开仓库，自动凭据遮盖不能替代人工检查。
