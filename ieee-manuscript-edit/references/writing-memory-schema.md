# 论文用词与术语契约

词表位置、结构、收录授权、检查时机、命令和状态统一按 [style-vocab](../../style-vocab/SKILL.md) 执行；本页只补充论文场景的选择。已有准确授权及未变化的实际读取结果继续复用。

## 论文加载

- 中文论文：`中文/通用.md` + `中文/论文.md`。
- 英文论文：`英文/通用.md` + `英文/论文.md`。
- 审稿回复改用对应语言的“审稿回复”表。
- 同一“不建议”发生重叠时，任务表覆盖通用表。
- 需要统一术语时再读全局 `术语.md`；项目 `术语.md` 覆盖同名全局术语。

## 当前论文与长期偏好

修改当前论文和维护词表分别按用户意图处理；新增候选、冲突译法也只在已授权的维护任务中记录。局部改文结合语境与专业含义判断，完整稿按 `style-vocab` 执行正式审计，不因每次写入重新扫描整稿。

审计命中是复核线索；术语一致性另按全局及项目术语表核对。保留检查程序的状态、内容指纹和定位信息，普通正文交付不附内部报告。
