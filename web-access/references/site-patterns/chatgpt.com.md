## 平台特征

- 生成图片保存在具体对话中，后续可在同一会话里继续基于原图编辑（2026-08-31 验证）。
- 页面进度可能长时间停在 99%，但刷新或重新打开同一对话后已经出现完成图片；进度显示本身不能证明生成失败（2026-08-31 验证）。
- 已加载图片的资源可能依赖登录态。浏览器外直接访问一次返回 `{"detail":"File stream access denied."}`，不能据此把会话中的图片判为不存在（2026-08-31 验证）。

## 有效模式

### 不确定进度恢复

提交后出现长时间 99%、连接中断或工具结果不确定时，刷新或重新打开同一对话，检查现有任务卡片、完成图片和明确错误。任何第二次生图提交都属于新的外部动作；授权和一次提交规则由 `research-schematic-imagegen` 管理。

### 保留同图编辑上下文

用户要求先确认底图再继续改图时，完成当前读取后以 `keep:true` 结束 task，让原对话 tab 留给用户和后续任务。不要另开新对话重建图片，也不要在用户确认前追加编辑。

### 已加载图片提取

先读取目标图片元素的 `currentSrc`、`complete` 和自然尺寸。服务器文件能正常取得时优先保存文件字节；直链因登录态被拒但图片已完整加载时，按 `references/cdp-api.md` 的自然尺寸图片像素导出流程处理。导出结果是页面已解码像素的 PNG 重新编码，不是服务器原始文件字节。

## 已知陷阱

- **重复提交**：99%或页面卡住不等于失败。未先恢复同一会话就再次提交，可能重复计费并产生多张图片（2026-08-31）。
- **直链拒绝**：浏览器外 URL 返回 file stream access denied 可能只是缺少会话权限，不能自动改用第二个网站或重新生成（2026-08-31）。
- **视口截图降质**：截图只保留当前视口渲染，不能替代自然尺寸生成图（2026-08-31）。
- **跨域画布**：画布不是权限绕过手段。资源跨域且不能证明 origin-clean，或 `toDataURL` 抛出 `SecurityError` 时停止（2026-08-31）。
