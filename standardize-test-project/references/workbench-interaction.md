# 工作台交互与状态检查

用于实验工作台的新建或局部修改；只检查本次涉及的行为。复用已有 TX/RX 模板，不为简单 GUI 引入串口、异步队列或扫描。具体字体、默认占格、子带频率和设备参数沿用项目批准配置，不升级为通用要求。

## 编辑与显示

- 同一参数只保留一个日常编辑入口；策略设置与仪器参数分开。数值和单位分开，显示真实批准范围，不补造能力。
- 自动编号、时间和只读状态用文本；互斥选项明确呈现。不适用控件真正禁用，相关回调及执行入口也检查当前条件。
- 常用操作和停止入口始终可达；控制区滚动或切换不挤压数据图。按实际窗口尺寸检查截图、截断和可读性。
- 分开草稿、已发送、可信回读和实测值。发送成功不等于回读一致；不一致时保留请求并显示实际值。
- 后台刷新不得改写正在编辑的文字、光标或选区；以请求身份和编辑版本拒绝迟到响应。存在未提交编辑或在途写入时，不悄悄使用旧设置开始正式测试。

## 任务、参考与历史

- 单次、重复沿用同一任务和保存路径。当前操作、正式次数、耗时与终态清楚可见；停止、失败和完成不能被普通观察刷新覆盖。剩余时间只在有估计依据时显示。
- 配置、通道或参考变化后清除当前旧指标；观察及异步结果同时检查采集帧、配置版本和参考身份。正式任务冻结所需条件，只允许其明确授权的受控调整。
- 主界面展示摘要，详细结果展示完整图件、分母和历史；两者对应同一记录。关闭结果窗口不停止任务，重新打开不重新采集或解调。失败不得显示旧成功结果冒充当前结果。
- 发送参考的逻辑身份与实际采集通道分别记录；通道变化不意味着参考一定失效，也不能跳过信号结构和参考一致性检查。单路实数、复数 I/Q 的通道与处理含义必须真实。
- 完整原始采集先保存；显示抽稀数据不能进入正式保存或 DSP。缺块、非有限数据、同步失败或分母不足显示无效原因，不显示零误码。重新分析生成新结果，不改原始记录。

## 模拟、设置与恢复

- 模拟使用正常工作台路径，信号与参考配套；模拟和实测偏好、参考及结果隔离。新进程验证关闭重开，不依赖原工程路径、临时注入或旧窗口状态。
- 区分常用实验设置、扫描起点和逐点实际设置。只有有效手动请求经可信回读确认后更新常用设置；外部变化、草稿、失败、迟到响应、自动量程、配平和扫描不覆盖它。
- 连接只读取设备状态；恢复实测设置需显式动作。按能力与参数依赖串行恢复、核验实际值；部分失败保留已写项目并停止，不静默重试。
- 日常测试与扫描分别遵守既定恢复策略；扫描开始前保存已确认起点，收尾和续扫不取最后一点或后来修改的偏好代替。新采集确认不能被设置快照替代。

## 受影响行为的离线验收

使用隔离结果和偏好目录，检查主进程及异步子进程零真实仪器访问。按改动选择：单次/重复、仅采集/解调、停止/失败、结果窗口关开与历史选择、输入编辑与迟到回读、模拟关闭重开，以及新项目完整复制/已有项目局部复用。断言真实控件动作、原始数据和状态变化，不只检查界面能打开。

模拟通过与实机验收分开报告；遇到未支持的设备能力应禁用对应功能，不以模拟值充当实机能力。
