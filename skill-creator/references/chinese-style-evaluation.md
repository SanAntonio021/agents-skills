# 中文文风评测

仅在评估中文文风、去 AI 味技能效果时使用。普通写作、代码审查、其他跨模型任务不套用本约定。

## 模型选择

- Claude 默认使用 Opus 4.6，调用标识为 `claude-opus-4-6`。用户为本次评测明确指定其他模型时，以用户指定为准，并记录覆盖值。
- 沿用用户当前选定的上游和认证；只在本次调用指定模型，不修改全局配置，不自行切换供应商。
- 对照双方使用相同模型、上游、输入材料、工具权限和运行参数，只改变待评测的技能内容。各组从新会话开始，多轮修改在组内续接原会话。
- 请求中显式传入模型，并核对返回的实际型号。模型不可用、型号不符或无法核实时，保留失败记录，不将该次输出计入有效比较，不自动降级或换模型。
- 上游或模型发生变化时另开一批比较，不与旧批次混算。记录请求模型、返回模型、非敏感上游标识、材料校验值、会话编号和执行结果；不保存认证信息。
- Codex 的模型选择不受本约定影响。技能描述触发测试使用被测宿主的实际模型，继续遵循主技能的 Description Optimization 流程。

## 验收

先核实规则是否实际提供给模型，再检查输出。调用成功只证明测试执行完成，不代表文风改善。事实、条件、修改范围和原文保护单独检查，文风按实际段落判断，不以禁词命中数代替评价。

模型选择程序至少覆盖：默认值、用户覆盖、多轮一致、返回型号不符拒收，以及其他宿主默认值不变。小样本试跑只验证调用与记录，不宣称稳定的文风优势。

## 本地维护

本技能保留 Anthropic 上游能力，仅新增本说明与主入口引用。来源见 [upstream-sources.md](upstream-sources.md)。上游更新先比较差异、测试并经批准后吸收，不自动覆盖本地约定。
