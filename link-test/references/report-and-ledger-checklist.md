# 台架结果与台账核对

这里只保留台架专业内容。人工记录的结构与篇幅由 `lab-notebook` 负责，数据和图片保存遵循 `standardize-test-project`。

## 结果含义

- 根据测试目标选取链路、仪器与通道、AWG OFF 底噪、AWG ON 带内功率、MER、BER、SyncPSNR 等实际结果；不要求每轮具备所有指标。
- 区分原始功率和解调指标。计算严格 On/Off Ratio 时使用同量程且相关条件一致的 noise 参考；条件不满足时说明差异，不把代理量标成 SNR。
- 保留条件、单位、失败状态和可定位的数据/图片来源。需要正式报告时复用这些材料，不补造缺失内容。

## 用户要求补台账时

- 按实际链路核对仪器、线缆、接头、射频模块和 DUT 配置，优先匹配型号、序列号及通道。
- 精确条目优先；只能找到最近似条目时明确标注，不当作已确认器件。仍不确定的事项保留待确认，不猜填型号。
- 更新用户指定的现有台账或相应备注，不自动新增另一份实验记录，也不把单次结论写成永久规范。
