# 飞书画板

飞书单个画板内图示能力的唯一入口：负责图型判断、图内容清单、原生对象创建与局部编辑、服务端回读、预览查看和完成判定。先读取 `lark-shared` 处理 CLI 身份和输出；需要浏览器局部编辑时读取 `web-access` 并运行其浏览器前检，使用返回的 Proxy 地址，不另建服务或抢占用户焦点。

## 入口与图型判断

先判断图的用途，不先问用户格式：

- **系统架构、硬件信号链、接线图、模块拓扑**：固定使用可编辑原生对象。主 Agent 直接完成建板、清单、编译、写入、回读和看图；只有多个互不依赖的画板需要并行时才拆子任务。
- **思维导图、时序图、类图、饼图、甘特图或其他非拓扑图**：原生对象合适就用原生；确实需要 Mermaid、PlantUML 或 SVG 时，说明原因和取舍，询问用户一次。用户不需要记住格式名称。
- **海报式视觉或高级插画**：先取得用户同意，再作为普通静态图处理。静态图不替代系统框图，不占用原生图位置的完成状态。

系统拓扑不自动进入任何非原生格式。原生写入或局部编辑失败时保留准确的文档和画板标识并报告未完成，不得改用 SVG 或其他格式冒充完成。

## 选择执行路径

- **查看或导出**：用 `lark-cli whiteboard +export`，支持 raw、preview、svg、source；先查该命令帮助确认参数。
- **新建系统框图**：由 `lark-doc` 创建空画板并取得文档 token、board token 和 block ID；用 `native_nodes.py` 编译图内容清单，经 CLI RAW 写入，再回读和查看预览。
- **编辑已有图**：先导出最新 raw，按 ID 和当前内容定位对象，通过本技能 runner 调用页面原生编辑器。局部编辑用于改字、尺寸、样式、图层、绑定线及分组等需要编辑器语义的操作。
- **明确请求非原生格式**：使用 CLI 对应输入格式；导入结果的文字和连线绑定能力有限。已有非空画板默认追加；整板替换必须在用户明确授权覆盖范围后另行处理，不能充当局部编辑失败的后备方案。

支持 Docx 与 Wiki 文档路由，包括同源 Docx 自动跳转到 Wiki；runner 先用 CLI fetch 解析并核对对应 Docx token、唯一目标画板和文档块，再核对实际页面 origin/path 与原生文档/画板身份。不同文档、跨源或未核实的路由写前拒绝。画板 token 与文档 token 不可互换；同一文档可能有多个画板，从最新读取结果识别目标，不能只靠相似文字或对象 ID 猜测。

## 系统框图的视觉表达

- 主信号链沿一个方向排列；驱动、本振与临时测量支路从不同侧接入。按信号角色少量配色，同类支路保持一致，颜色不代替端口和频率标签。
- 正常连接用实线；只在标定时换接的设备用独立虚线支路并标注“标定时换接”，不能画成同时连接的功分支路。
- 框内保留设备简称和必要型号；端口、频率放在对应连接附近，连接绑定到准确侧边。参考面确有必要时用小标记表示；操作解释留正文，不塞进设备框。
- 优先减少交叉、绕线和重复文字，再选直线或正交线。验收预览时核对标签遮挡、支路可辨性和实际接线含义；原生可编辑不等于排版已合格。

## 图内容清单与原生对象

先读 [调用方法](references/operations.md)。每张系统图先形成一份“图内容清单”，写下模块、模块文字、端口、连接两端、锚点、线型、箭头、线上文字、分组和必要样式；清单是写入与验收的共同依据，存放在当前任务过程材料中，不进入公开技能源码。

`native_nodes.py` 支持矩形、圆角矩形、椭圆、菱形、平行四边形、独立文本和绑定连线。形状文字属于形状节点本身；连线必须保留 `start_object`、`end_object` 和准确锚点。分组和端口是清单语义，不能伪造成 RAW 节点；需要原生分组时走已经验证的后台编辑操作。

新画板默认链路是“清单校验 → 原生 RAW 编译 → CLI RAW 写入 → RAW 回读 → 预览看图”。写后核对对象身份、文字归属、两端绑定、标签和层序，并实际查看截图的端口、频率标签、支路与遮挡；编译成功或工具返回成功都不是完成。

`whiteboard.py` 负责 CLI 快照、独立后台标签、操作前一致性检查、执行、保存等待与服务端回读；`editor.js` 仅调用已验过的网页编辑器命令与事务，不直接修改节点存储，不保存浏览器登录信息。新建和追加不依赖浏览器登录；浏览器只用于确需原生编辑器语义的局部操作。

操作包括框内及独立文本改字、多行、字号、字色、移动和尺寸；旧对象颜色、线宽、实线/虚线/点线；箭头、线标签新增/改写/清空、字号和文字框宽度、沿线位置和线上/上方/下方避让；直线、折线、曲线、自动直角线、中间路径点及曲线经过点拖动；无模板新增第一条绑定线、复用线样式新增连接、引用已有模块新增或改接任意一端，以及四边锚点。追加新模块后，CLI 不直接绑定旧模块；先追加模块或游离线，再用原生编辑器把两端绑定到已有模块。精确删除必须显式列出会级联删除的绑定线；换标签时保留原线，避免中间态断链。改动外框填充或层级后，要把数据回读的绑定关系与实际预览的可见性都核对。

组合/取消组合、顶对齐、水平等距、精确删除和同一会话紧接删除后的撤销沿用既有入口。独立旋转模块的顶对齐和水平等距按原生可见外框及实际选择顺序执行、保存和重开核验；尺寸、角度、格式、层序及连接保持。排列边界读数缺失或已改变时写前拒绝，不用未旋转坐标代替外框。新组合中被明确选中的绑定线，其所有已绑定端点也须选中；原生命令会排除跨选择边界的线，入口提前拒绝，不能保存成缺成员的组合。单端绑定线检查其已绑定一端，游离线保留既有入口。

已有一层组合可按成员 ID 原位改字、字号、样式、线标签与格式、避让、线型、路径及曲线经过点，也可移动或改模块尺寸。保留成员和组合 ID；只放行由成员几何推导并验证的父组包围框变化，其他成员世界位置和属性保持。父组的服务端矩形可能是旧缓存；仅在原生父矩形与同次完整成员可见包围框一致时接受已记录的缓存归一化。

其他形状类型、复杂嵌套、协作竞争等未经验证的情形先检查范围，不声称完整覆盖所有飞书对象。

## 执行与验收

1. 复用用户对目标与修改的准确授权。读取最新 raw；每次调用用新的过程子目录保存请求、修改前后快照和结果。
2. 打开画板前检查整批操作名称、参数、有限数值、对象列表和删除撤销顺序；静态非法末步也不能让前面步骤先写入。每步提交前再 inspect，核对文档、对象类型、绑定、锁定成员和实际原生选择。先新增标签再调整格式等顺序依赖按当时状态检查。编辑器指纹不匹配时停止相关写入，不能自动接受新指纹。
3. 每次只执行明确操作。端点改接先合并请求与保留端点，最终自连接写前拒绝；正常改接先解除旧绑定，再绑定新目标，并检查旧连接索引已清理。
4. 删除前列清目标及关联线；绑定线会随模块删除，范围不符就停止。完整级联集合不能移除保留组的成员，显式授权的整组删除仍可执行。撤销只用于本会话刚完成的删除，不当作跨会话或多人编辑的通用恢复方案。
5. 内容调用前记录已验原生发送通道的版本；提交后等待本次版本推进、发送队列清空且保存状态完成，再核对服务端 raw。旧页面序号与保存图标可能尚未反映防抖队列，不能单独证明本次保存。结果不明先读状态，不重新提交相对移动或新增；保留证据及尚未确认保存的页面。
6. 检查节点集合、文字、几何、绑定、分组关系和原生 render_alpha 及无关内容差异。移动和排列保持未请求的尺寸、角度、样式和层序；组移动核对每个成员的世界位移。新增、改接、锚点，以及移动、尺寸和排列受影响的绑定线，都独立计算实际附着点，并在保存和重开后核对。CLI raw 可能遗漏主题透明度和实际端点，不能以 RGB 或绑定 ID 正确代替可见效果验收。

每步在该步读取和预检前建立记录，保存事实与验收结论分开：未开始内容调用为未写入，调用开始而未确认保存为未知，服务端保存已确认后即使保护或重开失败仍为已确认。下一步读取失败也保留该步及此前已执行步骤。截图、证据文件写入和关闭失败不能改变已经确认的保存事实；结果文件无法写入时，调用方输出另带完整结果以保留步骤。已确认保存的自有页面正常关闭；未知写入保留页面并报告身份和收尾回执。追加在写前检查完整原生构造，只提交一次，随后有界只读回查；按真实ID映射核对新对象所有请求字段，重开后再导出完整raw保护新旧对象，并核对原生透明度和实际端点。请求中的画面检查同样执行。
CLI raw 省略或截断的标签宽度、换行模式、小数字号、曲线控制点及透明度变化，还要在原写入页面保留期间由独立新页面核对完整原生状态；匹配后才将该步保存记为已确认。等待与新页见证共用本次保存的总超时，不能以延长等待或旧值例外代替持久化证据。
追加对象按请求中的相对层序放到现有对象之后，保护旧对象的绝对层号；不以接受旧层号变化来修复追加。各等待入口及其阻塞传输共享本阶段的绝对截止，迟到回执不能通过；新页见证继承原保存截止，页面收尾另有有界预算。

改字、字号、宽度或位置会影响遮挡。使用 `capture_preview:true` 获取稳定截图和 `label_geometry`，实际打开截图检查标签与模块、其他标签及交叉线的关系；发现遮挡后再做明确的局部避让并重新查看。`visual_status:needs_review` 只表示截图可用，不能当作视觉通过。宽度与自动换行模式不在 CLI raw 中，`caption_format` 还必须重开核对原生属性；其他字段仍按 raw 保护。
标签小区域只做非空像素筛选，不能把短文字未达到整板像素门槛当作空白；是否可读和遮挡仍通过实际图像判断。
删除后紧接撤销在同一个编辑器完成逐步保存和回读，恢复成功后再重开；不要在两步之间另开页面。

发现用户或协作者同时修改时，以最新回读为准，停止冲突步骤；无法可靠探测所有其他标签和协作者，
不能宣称拥有独占锁。不要枚举或关闭用户页面。首次编辑可能规范化水平线高度，组合或删除可能重新编号图层，
只能解释已证实的具体差异，不能一律忽略非目标变动。

网页内部接口不是稳定 OpenAPI。当前已验接口版本及验证方式见 [兼容性与来源](references/compatibility.md)。
维护该技能或发布由 `skill-creator`、`agent-rules` 承接，普通绘图不进入维护流程。
