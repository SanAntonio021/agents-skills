# 内容与中文表达

写作前读取本文件。对已经选定的科研工作，先确定页面重点，再组织图文。工作是否纳入及是否展开按 [资料与选材](materials.md) 判断；本文件负责怎样讲清楚。已有准确自然的文字保持原样，专业术语和事实不为顺口而改。

## 展开页：先定重点

排版前，用一句话回答“这页希望导师知道什么”。这句话应能指出具体结果、判断、研究问题或实质进展；它是选材依据，不要求另设栏目或固定句式。

- **结果与比较**：先说观察或判断，再选能支撑它的图、数据和必要比较条件。
- **论文与方案**：讲清研究问题、方法或论证发生了什么实质变化。需要讨论具体研究内容或重要交付时再展开，不铺陈改稿和编译步骤。
- **实验准备与研发**：说明现在能开展什么实验、哪项关键问题得到解决及真实验证状态。没有量化结果也可以有实质进展；不要逐项介绍按钮、运行次数或保存步骤。
- **尚未解决的问题**：说明实际障碍及其影响，用现有现象或证据帮助讨论，不将假设写成已证实结论。

图件和正文围绕本页重点组织。同一判断的多张图可以合并；不同重要结果按理解需要分别表达。完整仿真输出或程序验收图只有在帮助解释本页问题时才展示，不能因为产物齐全就增加一页。

展开页应提供总览之外值得看或讨论的内容，例如关键图、比较依据或方法关系。只能复述总览的一句进度或数值、没有进一步可解释的材料时，合并简述。文字少但图能说明问题的页面照常保留；不为满足展开要求另添无关细节。

标题指明对象和主题；总结句直接写具体结果或推进。正文补充读懂结果所需的信息，不复述标题、总结和图中已清楚的标签。使用普通动词，例如比较、测量、讨论、修改、整理；“归集、支撑、框架”等词未说明具体内容时改写或删除。

## 必要信息判断

对一句话、一个参数或一段图注，智能体先试删，再指出实际影响：读者会把哪项对象、数值、条件、比较或结论理解错？影响本页判断的信息保留；只是说明工作做得完整、检查过或“更严谨”，留在项目记录。

- 保留决定数值含义和结论可信度的信息，如单位、比较基准、仿真假设、实测状态及必要样本量。不按数字、否定句或某类词一律删减。
- 仿真、离线、实测或原型状态在对应结果处准确交代。状态已清楚时不重复强调未做事项；必要限制仍须保留。
- 优先把条件写在主句、图例、坐标或紧邻数据的位置。同页标题、正文和图注已有表达，不要求每处再写一遍。
- 结论超出证据时，先缩小或修正结论。不要保留宽泛主张，再堆否定句补救。
- 来源追溯、原始数据、复现参数及执行日志保留在原记录。需要页面交代的来源和时期简短标明；历史数据不能变成本期新实测。
- 不为填满版面补背景、凑段落或缩字塞内容。听众读懂当前问题所需的背景仍在页面，不依赖备注或口头补充。

例如，比较曲线有误差棒时，“样本标准差，n = 3”影响读图，应保留。若图已经标明“仿真”，正文无须再写“目前只是仿真，未连接实物”。样本量、数据类型和限制是否保留，取决于实际结论。

## 总览页：工作缘由与实际推进

首页覆盖本次入选工作，同一工作的多个分析页合并说明。像向导师说明今天的工作一样，交代研究对象、本期具体工作和结果或状态；通常一至两句，按内容需要决定长度。

论文和方案先说具体研究内容，写稿进度需要时简短接在后面。“确定验证路线、完成引言”不能代替路线怎样安排、准备考察什么问题。简单事项直接说工作和结果即可，不强制补齐背景、目标、行动、结果四段。

沿用用户确认的内容、详略和真实状态。总览概括主要推进，详细参数由展开页承担，不重复堆叠过程细节和未做事项。

以下为虚构表达示例，不作为用户成果或固定模板：

- 变频论文：“讨论了复用商用通信设备、通过外部混频器提高工作频段的方法。论文将考察驱动条件、变频损耗、杂散和业务传输性能，并按先验证器件、再开展通信的顺序安排实验。”若修改引言本身值得交代，可简短接上进度。
- 双向通信论文：“讨论提高发射功率后，自干扰和接收前端非线性对通信的影响，明确实验需同时考察频率和功率范围。整理已有文献，继续修改引言。”

## 下一步：写近期行动

只写用户或项目记录已经确定的安排，集中在末页。每项说明要做什么；行动目的无法从上下文看出时，简短补明要解决或确认的问题。保留必要先后顺序，不强制重述项目总体目标，不顺势扩展成长记录、多随机种子、完整扫描等整套检验流程。

助手新建议须先确认。安排确实缺失且影响本次交付时询问该缺口，继续其他已明确内容；用户要求先生成时可简记“后续安排待确定”，不为填末页造任务。用户删去的安排不自动恢复。

例如，已确认获取产品数据时可写：“向厂家询问目标频点的输出功率、相噪和杂散，与现有频率源比较。”无需在同一句铺开全部采购、建模和实验计划。

## 通用写作与个人词表

起草及交付前执行表达检查。已安装 `writing-router` 时，实际读取其 `references/common-quality.md` 与 `references/ai-smell-catalog.md`，沿用通用质量规则，不重新进入写作路由或增加确认。未安装时按本文件完整检查，不要求补装。

个人词表使用用户指定文件或项目根目录的 `汇报词表.md`；已配置 `style-vocab` 时沿用其加载与检查。个人偏好优先，不改变专业含义。没有个人配置时执行下表的基础检查，不读取作者私人路径，也不将词表写入 PPT 或分享包。写作资料只在用户要求时维护。

| 需结合语境检查 | 通常的处理 | 专业例外 |
|---|---|---|
| 赋能、助力、至关重要、彰显 | 写具体作用或结果，无信息则删 | 引用、固定名称 |
| 深入探讨、聚焦 | 直接说明分析或讨论的对象 | 光学聚焦等术语 |
| 闭环、沉淀、落地 | 写具体完成的工作及状态 | 闭环控制、化学沉淀、着陆 |
| 口径、对齐、拉齐 | 写定义、统计方式或统一什么 | 天线口径、时间或相位对齐 |
| 维度、颗粒度、收口 | 写比较变量、详细程度或完成事项 | 数学维度、工艺收口 |

这些是判断提示，不是禁词表，不做全文替换。

## 内容验收

在排版前检查内容稿，完成 PPT 后再提取全部可见文字并直接查看图片内文字。按下列顺序判断，不只检查用户指出的一句：

1. **全套重点**：本期主要科研推进是否清楚，用户要求讲的内容是否遗漏；是否给常规过程细节过多篇幅。
2. **逐页价值**：合起来读标题、总结、正文与图件，能否讲清这页最值得知道的内容；找不到独立内容时合并或删页。
3. **证据与事实**：主张是否有材料支持，对象、数字、单位、状态、时期和比较条件是否准确，必要背景与限制是否足够。
4. **取舍与表达**：逐句执行必要信息判断，删重复、空话和无关过程；名称明确，文字自然好懂。总览及下一步分别按对应章节检查。

在已有过程记录中简记实际取舍及必要保留项，内容验收与文件/排版验收分开。词表零命中、文件有效或图文不溢出都不能证明内容合格。

同一任务中材料与正文未变化时复用已完成检查；修改后检查受影响内容及上下文，最终通读全稿。删并页、增页或调序后同步页码、编号和引用。后续修改以用户当前稿为准，检查方法不得变成恢复已删除内容的理由。
