# English General Style

| 不建议 | 建议 | 例外 |
|---|---|---|
| delve | examine; analyze | quoted text, titles, source names |
| leverage | use; apply; build on | finance, mechanics, lever contexts, quoted text |
| utilize | use | quoted text, formal terms in cited standards |
| showcase | show; demonstrate | exhibition or product showcase as a noun |
| pivotal | important; central | literal pivot or mechanical contexts |
| intricate | complex; detailed | quoted text |
| seamless | smooth; continuous | quoted text, actual seam-free manufacturing contexts |
| tapestry | system; set; pattern | textile or art contexts, quoted text |
| underscore | show; indicate | code character `_`, quoted text |
| furthermore | also; in addition; omit if redundant | quoted text |
| crucial | important; necessary | quoted text |
