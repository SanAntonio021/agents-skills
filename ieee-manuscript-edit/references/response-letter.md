# 审稿回复写作规范

用于起草、重排和审校逐条回复审稿意见的正文（Response Letter）。中文和英文回复信用同一套结构。

## 结构：一问、一答、一展开

1. **拆问题。** 一条审稿意见通常包含几个要点。每个要点写成一个问题，配一个回答，自成一小节，顺序与审稿人原文一致。意见只有一个要点时，也写一组“问题/回答”。
2. **每小节先写两行。** “问题：”和“回答：”各占一行，中间空一行。“问题：”尽量用审稿人原话，可以缩短。“回答：”用一句话给出直接答案。
3. **答完紧接着展开。** 依据写在本小节的“回答”下面，写完再进入下一个问题。各问的答案不集中放在回复开头；答案离开依据会显得弱。依据有三段以上、各讲一件事时，每段加编号小标题，写法见“版式”。
4. **正面回答。** 审稿人问什么，先点出这个问题，再回答。审稿人明确要求补实验、补比较或改正文时，直接交代做了什么。
5. **每条回复自成一体。** 不写“见 R4-2”这类指向其他回复的话。需要的内容在本条内重述。

## 展开：结论在前，依据写足

6. **结论在前。** 每段先说这段要说明什么，再给算法、推导或数据。次序反了，读者看不出这段的用途。
7. **公式单独成行。** 公式后面用“其中”逐个定义变量。多个公式不挤进一个括号或一句话，宁可篇幅长一些。这样审稿人读起来舒服，也体现回复认真。
8. **用具体数字。** 含糊说法换成具体数字，不用“大致”这类模糊词。能用公式或数据证明的，写出公式和数据。
9. **写明数字的性质。** 结果数字写明是实测、由实测数据换算，还是离线推算。推算结果不写得像实测。实验条件（如温度、测试点数）不标性质。

## 语气

10. **不辩解。** 不写防御性、反驳式语句，不预先辩解。

语气保持客观。对受客观条件限制的意见，说明原因和已做的最小充分补充。

## 收尾

11. **修改内容。** 放在本条回复末尾，逐项对应正文的实际改动。没有改动正文时，写“本条未改动正文”。
12. **引用。** 回复中引用的文献在本条末尾单独列出，不留占位符。
13. **口径一致。** 术语、章节与图表编号、数字精度与正文相同。

## 版式

```markdown
### Rn-m 标题

**审稿意见**

> （审稿人原文，保持原样）

**回复**

（开场一句）

**问题 1：** （审稿人原话，可以缩短）

**回答：** （一句话的直接答案）

（依据只有一两段时直接写：先说这段要说明什么，再给公式、数据或推导。公式单独成行，后面用“其中”定义变量。）

**问题 2：** ……

**回答：** ……

**（1）短标题：** （第一段依据）

**（2）短标题：** （第二段依据）

**（3）短标题：** （第三段依据）

**修改内容**

1. （位置）：（实际改动）（对应问题 n）

**本条引用**

[1] ……
```

- **层次。** 一条回复有三层：一条审稿意见；意见里的要点，每个要点一组“问题 n / 回答”；回答下面的依据段落。“问题 n”的序号在每条回复内从 1 开始。在台账备注或讨论中提到某个问题时，带上意见编号，例如“R1-1 的问题 2”。
- **依据段落的小标题。** 一个回答下面的依据有三段以上、各讲一件事时，每段以“（n）短标题：”开头，序号在每个问题内从（1）开始。小标题说明这一段讲什么，不重复“回答”那句话。依据只有一两段，或者是一步接一步的推导（写“第一步”“第二步”）时，不加小标题。
- **加粗。** 只有标签和小标题加粗：“审稿意见”“回复”“问题 n：”“回答：”“（n）短标题：”“修改内容”“本条引用”。正文不加粗。
- **讨论稿的标签。** 中文讨论稿（台账）里的审稿意见是译文时，沿用 `journal-submission` 模板的标签“审稿意见（中文）”“中文回复：”，其余写法相同。
- **省略。** 没有改动正文时，“修改内容”下只写一句“本条未改动正文。”没有引用文献时，不写“本条引用”。

## 示例（虚构）

下面的题目、数据、审稿意见和文献都是虚构的，只用来示意版式。

```markdown
### R2-3 内阻估计误差的计算与比较

**审稿意见**

> 作者称所提方法的内阻估计误差低于传统脉冲法，但没有说明误差如何计算，也没有给出定量比较。请补充两种方法的定量比较。另外，表 3 中 −20 °C 的结果是实测得到的吗？

**回复**

感谢审稿人的意见。下面按意见中的三个问题逐一回答。

**问题 1：** 误差如何计算？

**回答：** 误差按均方根误差计算，参考值由阻抗分析仪测得。

误差的定义和各个量的来源如下。

$$
e_{\mathrm{RMS}}=\sqrt{\frac{1}{N}\sum_{n=1}^{N}\left(\hat{R}_n-R_n\right)^2}
$$

其中，$\hat{R}_n$ 是第 $n$ 个测试点上的内阻估计值；$R_n$ 是同一测试点上由阻抗分析仪测得的参考值；$N$ 是测试点总数，本文 $N=120$。

**问题 2：** 请补充两种方法的定量比较。

**回答：** 已补充：25 °C 下所提方法的均方根误差为 0.42 mΩ，传统脉冲法 [1] 为 0.91 mΩ，所提方法低 53.8%。

**（1）比较条件：** 两种方法在同一组 120 个测试点上各测一遍，温度为 25 °C，误差按问题 1 的定义计算。

**（2）两种方法的误差：** 所提方法为 0.42 mΩ，传统脉冲法为 0.91 mΩ。两个数字都是实测结果。

**（3）降低比例的算法：** 53.8% 由上面两个实测结果换算得到：

$$
\eta=\frac{e_{\mathrm{pulse}}-e_{\mathrm{prop}}}{e_{\mathrm{pulse}}}\times 100\%
$$

其中，$e_{\mathrm{pulse}}=0.91$ mΩ 是传统脉冲法的均方根误差；$e_{\mathrm{prop}}=0.42$ mΩ 是所提方法的均方根误差；$\eta$ 是所提方法相对传统脉冲法的误差降低比例。

**问题 3：** 表 3 中 −20 °C 的结果是实测得到的吗？

**回答：** 不是；−20 °C 一行是离线推算结果，0 °C、10 °C 和 25 °C 三行是实测结果。

−20 °C 的数值由三个实测温度点线性外推得到。实验所用恒温箱的最低温度是 0 °C，因此没有 −20 °C 的实测数据。外推关系为

$$
e(T)=e_0+kT
$$

其中，$e(T)$ 是温度 $T$（单位 °C）下的均方根误差；$e_0$ 是 0 °C 时的均方根误差；$k$ 是均方根误差随温度变化的斜率。$e_0$ 和 $k$ 由三个实测点拟合得到：$e_0=0.52$ mΩ，$k=-0.004$ mΩ/°C。三个实测点依次是 0 °C 时 0.52 mΩ、10 °C 时 0.48 mΩ、25 °C 时 0.42 mΩ。代入 $T=-20$ °C，得到 0.60 mΩ（离线推算）。

**修改内容**

1. 第 3.2 节：新增均方根误差的定义式和变量说明（对应问题 1）。
2. 第 4.1 节：新增表 4，列出两种方法在 25 °C 下的均方根误差和误差降低比例（对应问题 2）。
3. 表 3：新增“数据性质”一列，−20 °C 一行标为“离线推算”，其余三行标为“实测”；表注给出外推关系（对应问题 3）。

**本条引用**

[1] 作者甲, 作者乙. 脉冲法内阻测量示例[J]. 示例期刊, 2020, 1(1): 1–8.（虚构条目，仅示意格式）
```

示例里，问题 2 的依据有三段、各讲一件事，所以加了编号小标题；问题 1 和问题 3 的依据各是一段说明加一个公式，不加。

## 中英文对应

英文回复信沿用上面的结构，句子按英文论文规则写。

1. **结构一一对应。** 中英文两版的问题数量和顺序、小标题、公式、数字、数字性质、“修改内容”条目和引用相同。英文不因句子规则合并或删除小节。
2. **标签对应。** 见下表。

| 中文 | 英文 |
|---|---|
| 审稿意见 | Comment |
| 回复 | Response |
| 问题 n： | Question n: |
| 回答： | Answer: |
| （n）短标题： | (n) Short heading: |
| 修改内容 | Changes in the manuscript |
| 本条未改动正文。 | No change was made to the manuscript in response to this comment. |
| 本条引用 | References cited in this response |
| 其中 | where |
| 实测 | measured |
| 由实测数据换算 | calculated from measured data |
| 离线推算 | estimated offline |

3. **时态。** 已完成的修改用过去时或现在完成时，例如 “We added Table 4 to Section 4.1.”，不用 “we will add”。
4. **句子规则。** 中文回复按[中文论文](chinese-paper.md)，英文回复按[英文论文](english-paper.md)，只加载当前语言的一份。英文需要逐句审查时，按需加载 [Sainani 五轮检查](sainani-sentence-review.md)。本文件只管结构和内容，不重复句子规则。
5. **词表。** 中文加载 `style-vocab` 的“中文/通用”和“中文/审稿回复”，英文加载“英文/通用”和“英文/审稿回复”。

英文骨架：

```markdown
**Question 1:** (the reviewer's words, shortened if needed)

**Answer:** (a one-sentence direct answer)

(Support: state what the paragraph shows, then give the equations, data, or derivation.)

**Question 2:** …

**Answer:** …

**(1) Short heading:** (first supporting paragraph)

**(2) Short heading:** (second supporting paragraph)

**(3) Short heading:** (third supporting paragraph)

**Changes in the manuscript**

1. Section 3.2: …

**References cited in this response**

[1] …
```

## 与其他规则的关系

本节只引用现有规定，不新增要求。

- **期刊规定优先。** 决定信或投稿页面规定了回复格式时，以其为准（`journal-submission` 的 `references/lifecycle.md`）。
- **编号和台账。** 意见编号、台账字段和原始意见的保存按 `journal-submission` 的 `references/material-templates.md`。
- **只润色时不重排。** 用户只要求润色或翻译时，保持原有结构、编号、事实、修改位置和证据。
- **保留科学限定。** 按第 10 条删防御性语句时，实验假设、比较基准、不确定性和已知限制要保留（[定稿规则](draft-finalization-rules.md)、[中文论文](chinese-paper.md)）。第 9 条的数字性质属于这类限定。
- **改公式版式要核对。** 把已有回复里的公式改成单独成行时，逐项核对符号、上下标、数值、精度、单位和运算关系（`writing-router` 的[共同质量规则](../../writing-router/references/common-quality.md)）。
- **篇幅来自内容。** 第 7 条增加的篇幅是公式、变量定义和数据，不用套话或重复句子加长。
- **重述不算重复。** 按第 5 条在不同回复里重述同一内容，不按全文重复规则合并。
