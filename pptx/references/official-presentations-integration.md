# 按需读取官方 Presentations

仅在已经选定官方制作路线时使用本说明。隐藏官方技能发现入口不等于关闭插件；不临时重新启用技能，不修改官方包，也不通过隐藏的技能名调度。

## 定位与交接

运行本技能的 `python scripts/resolve_official_presentations.py`。脚本只读当前 `codex plugin list --json` 的登记，由唯一已安装且启用的 `presentations@openai-primary-runtime` 的 `source.path`、插件清单和一致版本定位原版技能。它不遍历缓存选最新版本，也不依赖技能发现目录。

- `status=available`：直接读取返回的绝对 `skill_path`，以 `skill_dir` 解析其相对参考及工具。把选定路线、版本、技能路径和制作工程位置记入已有任务记录。
- 交接已确认的页面内容、模板、设计决定、素材、交付要求和剩余问题。已回答的官方澄清项复用原答案；缺失的关键决定才补问。原版制作与内部检查仍执行。
- 按原版要求调用 `load_workspace_dependencies` 核实 Node、`@oai/artifact-tool` 和 Python 运行环境。定位结果只证明登记及必要文件存在，不能充当运行库就绪、制作成功或质量验收证据。
- 官方制作结束后进入本地验收部分，不再从路线选择开头执行。修复继续使用同一制作工程；同一文件版本已经满足的检查可以复用，仍完成未覆盖的 PowerPoint 原生及逐页视觉验收。

## 不可用与版本变化

脚本输出 JSON，成功退出码为 0；不可用退出码为 1 并提供 `reason`。缺失、登记歧义、版本不一致、引用文件缺失或 CLI 失败均不退回旧缓存。诊断不打印 CLI stderr 或配置内容。

开工前不可用时，按制作路线规则选择已经通过完整性检查的 PPT Master 备用路线并记录原因；制作开始后不可用则保留工程，处理具体缺失，不擅自切换制作工具。每个新任务重新定位，插件更新后的版本不能继承旧版本的制作验收。隐藏入口的精确路径配置由维护流程核对更新，定位脚本不改配置。

`--plugin-list-json <fixture.json>` 只供隔离测试，输出 `evidence_mode=fixture`；不得用作真实安装或发布生效证据。默认模式为 `live`。
