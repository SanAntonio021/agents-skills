# ScholarOne Manuscripts

平台归属：Silverchair。资料最后核对：`2026-07-26`。官方入口见 [../../journal-submission/references/official-source-index.md](../../journal-submission/references/official-source-index.md)。

## 适用边界

ScholarOne 是高度可配置平台。Silverchair 作者指南提供示例流程，但目标期刊可以增加、删除、重命名或重排字段。当前页面和目标期刊当日指南始终优先，不把其他 ScholarOne 站点的页序或按钮复制到本次 IEEE 投稿。

## 作者与机构

- 先搜索并选择平台提供的规范机构记录。
- 无匹配时，只使用当前站点正式提供的自由文本或 not listed 路径。
- 项目状态记录 `matched`、`manually_entered` 或 `not_listed`。
- 作者顺序、通信作者、投稿联系人和作者增删必须单独确认。

## 文件与 proof

- 文件类型和顺序按当前站点配置处理。
- Review & Submit 可能提供 HTML 和/或 PDF proof；不要求不存在的格式。
- LaTeX 稿件可能没有 HTML proof。只查看当前页面明确要求的 proof/preview。
- 查看后仍要确认文件顺序、正文可读性、匿名要求和阻断错误。

## 最终提交

停在最终 Submit 前，展示审查门、作者、文件、声明、审稿人和 proof 摘要。最终 Submit 和确认由用户亲自操作。
