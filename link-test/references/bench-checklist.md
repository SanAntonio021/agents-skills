# 台架测试执行清单

## 测前核对

- 沿用本轮已确认的条件和项目配置，读回 AWG OFFSET、示波器插值、平均次数、增强分辨率与 OptimizeGroupDelay。
- 未指定设置时先记录现状；只有影响本轮测量含义且无法从已有要求确定做法时才询问。不自动重置成固定基线。
- 对应参数路径与可选参考设置见 [LeCroy 前处理映射](preprocessing-mapping.md)。
- 核对当前链路、仪器和通道，必要信息随本轮数据保存。

## 测试类型选择

- 只看链路通不通：单次 `SMOKE`
- 看原始质量：`AWG OFF/ON` 配对功率
- 看可解调性：功率 + full demod
- 看长期稳定性：固定工作点重复多轮

## 量程与新采集

- 日常自动量程按当前项目已授权策略执行；观察阶段只提醒，不写量程。固定量程实验及 OFF/ON 配对保持比较条件，不套用日常自动调整。
- 用完整波形、可信量程和示波器偏移判断屏幕占用及余量；ADC 削顶另行检查，不能从截断峰值推断安全量程，也不把显示抽稀或描述符解码系数当作判断依据。
- 支持直接计算请求的路径不预先取整为假定档位。分别记录每路请求、实际回读和已写项目；允许有效的设备规范化响应，不因请求不等于实际就判失败，也不宣称已证明设备选择了最近值。
- 实际回读须有限、正数且与完整状态一致；依次下发、核验、稳定等待、启动新采集并确认完成。新波形安全才接受实际量程；不得为凑足目标占格反复调整。未验证的精细开关、范围及命令不猜测。
- 调整次数按正式点计入预调；同值不重复写。未达安全条件时按项目规则在预算内调整，遇到无效回读、状态不一致、无进展、循环、设备拒绝或预算耗尽则停止。部分写入失败保留已完成项目，停止余下写入，不静默重试。
- 缓存只能避免重复写入，不能替代新波形检查；仪器、来源、通道、配置、参考或可信设置变化及失败后使相关缓存失效。
- 条件合适时单次只需一次正式采集，重复 N 次取得 N 次正式结果，不固定附加试采。量程检查帧保存但不解调、不计正式次数；零信号和无效数据停止并说明，不无限重采。
- 每次正式采集仍需启动并确认新采集，原始数据保存成功后推进正式计数。通信质量差但采集有效的结果照常记录；解调失败保留波形，不补测掩盖失败。
- 自动配平遵守原有物理映射与板卡门禁；换量程影响不能归因于板卡，退化确认期间冻结比较条件，条件失效时保留诊断并暂停。

## 设置与收尾

- 常用设置、扫描起点及逐点实际设置分别保存。手动写入且可信回读确认后才更新常用设置；连接看到的外部状态和自动调节不覆盖它。
- 普通测试按既定策略保留最终合适量程；扫描在开始调整前保存明确来源、已恢复核验的起点，结束/异常/停止恢复并核验该起点。续扫沿用原轮次基准，不换成最新偏好或最后测量点。
- 停止先阻止后续控制，等待在途动作完成或超时，再按设备所有权和项目策略收尾；保留已有 AWG 关闭优先顺序。独立 RX 会话不擅自关闭 TX 的 AWG。
- 收尾不被普通停止标志跳过。恢复失败不阻断其他必要收尾；记录未恢复项目，不强杀持有仪器的进程并立即重连，也不保证进程强杀后能可靠恢复。

## 按测试目标选取的指标

只选本轮实际测量或计算的指标，区分功率、解调结果与采集状态；不为补齐清单虚构数值。

- `InBandNoisePower`
- `InBandOnPower`
- `OnOffRatio_dB`
- `MER`
- `BER`
- `SyncPSNR`
- `ClipFraction`
- `ActualVdivVPerDiv`

## 常见误区

- 不同 `V/div` 的 `AWG OFF` 噪声不能直接拿来做严格的开关功率比。
- 没有同量程 noise 参考时，不要把代理量硬写成 `SNR`。
- 量程尚未验证有效时，先完成有界量程检查；检查帧不混入正式重复次数。
- 链路功率摸底阶段，不要过早把 `MER` 当唯一结论。
