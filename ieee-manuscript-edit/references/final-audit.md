# 论文终稿审校

本文件只用于 `mode=final_audit`。同时加载当前正文语言对应的规则，不自动加载另一语言。沿用当前请求的范围和只读限制；终稿文字审校核对表达、前后一致及科学含义是否漂移，明确要求科学论证或全文引用支撑审查时再交 `paper-review`。已发现的明显事实问题仍指出。

## 审校顺序

1. 核对当前文件和范围；使用审计工具时保留其输入 SHA-256 和定位信息，复用版本未变且覆盖本轮范围的检查。
2. 核对论点、支撑材料与章节作用的对应关系，检查摘要、正文、图表和结论。
3. 检查数字、单位、公式、变量、实验条件、比较基线和引用。
4. 检查缩写作用域、图注自解释、术语一致性和交叉引用。
5. 检查全文重复和 AI 气味；先保护科学限定，再处理句式。
6. 获准修改后检查受影响内容，完整稿按 `style-vocab` 的时机复扫；工具结果对应修改后文件，不能沿用失效的哈希或行号。只读审校不产生替换稿。

## 关键判断

- 摘要和结论可以复述核心结果，但需压缩并承担各自功能；整段复制判 `fail`。
- 结果段写观察事实，讨论或分析段解释原因和意义。两处只是换词重复时合并。
- 中位数、百分位数、CDF、置信区间等统计量要说明它们回答什么问题。
- 图注应说明对象、条件、面板、图例、单位和主要读法；图片存在时查看图片后判断。
- 固定间接否定、`fail to`、`neither...nor` 等结构不能仅因关键词命中就改写。
- 目标期刊格式只有在官方模板或作者指南核对后才能称通过。

## 工具边界

规范审计脚本只适用于英文 Markdown 和单文件 LaTeX：

```text
python -X utf8 scripts/audit_manuscript_conventions.py --input <path> --format json
```

中英文词表审计使用 [style-vocab 的现有命令](../../style-vocab/SKILL.md#检查)：`--file`、`--language`、`--document-kind` 及适用的词表目录；不要使用规范审计脚本的参数调用词表脚本。

退出码和候选项按各脚本说明解释。中文稿由当前助手结合原文审校，并按适用时机运行词表审计；规范脚本不能代替中文审校，也不能判断图片语义、事实真实性或引用是否真正支持论点。

按共同质量规则在对话中分点说明必要问题，原稿位置及相关原句足以定位即可。哈希、计数及工具日志保留在内部检查结果中；用户明确要求审计记录或表格时提供，不作为每次交付的固定附录。

## 失败条件

- 虚构或漂移的数字、公式、引用、设备和实验条件；
- 把计划、仿真或计算升级为实现或实测；
- 摘要、正文或结论存在无理由整段复制；
- 同一指标在图、表和正文中互相矛盾；
- 结论超过实验和证据的适用范围。
