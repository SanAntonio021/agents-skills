# 跨时钟域与复位

列出各时钟域、频率关系、复位来源与释放条件；对每条跨域信号说明是稳定电平、脉冲、相关控制总线还是连续数据流，再选择结构。

- 单比特稳定电平可使用适用同步器；窄脉冲不能仅靠两级采样保证捕获，应使用符合源目的速率与握手约束的脉冲或请求同步结构。
- 相关多比特数据不能逐位独立同步。按更新速率选择稳定数据加握手、异步 FIFO 等，优先复用经验证的工程模块或适用 XPM。
- Gray 编码只适用于满足其变化与采样假设的量，不能将任意数据总线直接换成 Gray 视为解决跨域。FIFO 还需核对指针、满空、复位和约束。
- 复位方式沿用项目要求。需要异步置位、同步释放时对每个域分别处理；检查时钟未稳定、复位先后次序、在途请求和单侧复位后的恢复。不要为了统一风格更改既有 IP 复位语义。

结构确认后交给 vivado-constraints 检查约束与 report_cdc。时序 false path 不保证数据一致性，仿真也不证明亚稳态安全；CDC 告警按具体结构核对，不能全部豁免。

依据：[AMD PG382 XPM_CDC_ARRAY_SINGLE](https://docs.amd.com/r/en-US/pg382-xpm-cdc-generator/XPM_CDC_ARRAY_SINGLE)。该模块面向互不相关的比特；相关总线需要其他适用结构。实例参数、复位和时钟要求须读取安装版本对应的宏文档。
