# English Paper Style

| 不建议 | 建议 | 例外 |
|---|---|---|
| robust | stable; reliable; validated | robust statistics, robust control, quoted text |
| built on（架构基于器件） | based on | “builds on prior work” and software or system-integration contexts |
| so that（表机制结果） | whereby | a genuine purpose clause |
| enter as（损伤表现） | manifest as | — |
| compensate（泛指缓解损伤） | mitigate | standard DSP terms such as I/Q imbalance compensation, CFO compensation, and predistortion |
| experiment day / the day's conditions | on the day of the experiment | — |
| 弱化情态（Future work） | includes; should be explored; will test | genuinely uncertain projections |
| can + 动词（已验证能力） | use the simple present, such as “delivers” | unverified potential capability |
| signal-layer 等自造复合词 | plain wording, such as “how the signals are defined” | — |
| error-free（作表语时） | error free | retain the hyphen when used attributively, such as “error-free acquisitions” |
