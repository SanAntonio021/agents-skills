# 图、表、公式检查清单

本文件用于保证单篇论文总结不漏掉图表和公式证据。

## 图表

1. 先列出主文所有 `Fig.`、`Table`、`Extended Data`、`Supplementary Fig.`、`Supplementary Table`。
2. 使用原文编号。中文正文可写 `图 1`、`表 1`、`补充图 2`，数字必须与原文一致。
3. 每张纳入正文的图或表后写一句中文导读，说明读图时看什么。
4. 如果编号跳跃，写明缺号原因：抽取失败、低置信、重复、补充材料不可用、与当前总结范围无关。
5. `debug_pages/`、`embedded_candidates/`、整页渲染图只用于排查，不放入正文。
6. 表格和图片同等处理。HTML 表格优先保留为 Markdown 表格，PDF 表格截图作为兜底。

## 公式

1. 列出关键公式编号和所在章节。
2. 写清公式用途：建模、估计、优化、均衡、评价指标、链路预算或误差分析。
3. 写清主要变量含义和单位。原文未说明时写 `未说明`。
4. 对通信论文，优先检查速率、带宽、BER/EVM/SNR、容量、信道矩阵、均衡器、损伤模型相关公式。
5. 不把公式只写成“使用某公式”。至少说明输入量、计算过程和输出量。

## 证据定位

关键结论尽量关联到原文位置：

- section
- page
- figure
- table
- equation
- supplementary note

没有可靠页码或编号时，写章节名或图表题名附近位置。
