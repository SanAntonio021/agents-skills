# 无上下文读者测试

这是一个可选的可读性检查，用来判断陌生读者能否在没有对话背景的情况下理解文稿。它不替代
事实、证据、合规或投稿规则核查，也不自动改变 A/B/C 分级。

## 做法

1. 从当前稿件复制一个完整、可定位的章节或摘要，去掉当前对话中的解释、用户意图和修改历史。
2. 只依据这份文本，记录第一次阅读时无法确定的对象、缩写、因果关系、结论范围和下一步动作。
3. 为每个问题标注最小缺口：缺定义、缺证据、缺过渡、缺限定语，或只是风格偏好。
4. 把会影响准确理解、执行或审稿判断的问题归入 A/B 类；只影响口味的问题归入 C 类。
5. 给出一到两条最小补救建议，保留原文定位。没有问题时明确写“未发现上下文缺口”。

## 边界

- 仅使用本地稿件和用户提供的材料；不调用外部读者、网络服务或模型 API。
- 不为了让文本“更像人”而添加事实、个人经历、引用或第一人称。
- 不把读者测试的通过写成“证据充分”或“可以投稿”；正式投稿仍需走 `submission-gauntlet`。
