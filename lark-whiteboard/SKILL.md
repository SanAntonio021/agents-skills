# 飞书画板

本地维护的原生对象编辑技能。先读取 `lark-shared` 处理 CLI 身份和输出；需要浏览器时读取
`web-access` 并运行其浏览器前检，使用返回的 Proxy 地址，不另建服务或抢占用户焦点。

## 选择路径

- **查看或导出**：用 `lark-cli whiteboard +export`，支持 raw、preview、svg、source；先查该命令帮助确认参数。
- **新建系统框图**：由 `lark-doc` 创建空画板并取得 board token；用本技能生成带内嵌文字的原生形状和绑定连线，再追加到画板。
- **编辑已有图**：先导出最新 raw，按 ID 和当前内容定位对象，通过本技能 runner 调用页面原生编辑器。
- **明确指定 Mermaid、PlantUML 或 SVG**：仍可使用 CLI 对应输入格式；这类导入不保证形状内文字和连线绑定。已有非空画板默认追加；整板替换必须在用户明确授权该覆盖范围后另行处理，不能充当局部编辑失败的后备方案。

画板 token 与文档 token 不可互换。同一文档可能有多个画板；从文档最新读取结果识别目标，不能只靠相似文字或对象 ID 猜测。

## 原生对象与操作

先读 [调用方法](references/operations.md)。源码中的 `native_nodes.py` 生成矩形、圆角矩形以及绑定两端的连线；
文字属于形状节点本身。不要使用会把文字拆成独立节点的 DSL 转换结果来假装“框内文字”。

`whiteboard.py` 负责 CLI 快照、独立后台标签、操作前一致性检查、执行、保存等待与服务端回读；
`editor.js` 仅调用已验过的网页编辑器命令与事务，不直接修改节点存储，不保存浏览器登录信息。

第一版操作：框内改字、多行及字号，移动、尺寸，箭头、添加线标签、直线/折线，复用现有线样式新增连接、改接终点，
组合/取消组合、顶对齐、水平等距、精确删除，以及同一会话紧接删除后的撤销。
任意折线拐点、旧图独立文字迁入形状、替换已有线标签暂不自动处理。
其他形状类型、复杂嵌套、协作竞争等未经验证的情形先检查范围，不声称完整覆盖所有飞书对象。

## 执行与验收

1. 复用用户对目标与修改的准确授权。读取最新 raw；每次调用用新的过程子目录保存请求、修改前后快照和结果。
2. 先 inspect，核对文档、画板、对象、文字和几何。编辑器指纹不匹配时停止相关写入，不能自动接受新指纹。
3. 每次只执行明确操作。端点改接先解除旧绑定，再绑定新目标，并检查旧连接索引已清理。
4. 删除前列清目标及关联线；绑定线会随模块删除，范围不符就停止。撤销只用于本会话刚完成的删除，不当作跨会话或多人编辑的通用恢复方案。
5. 页面序号收敛只是辅助条件；必须用服务端 raw 回读确认修改。结果不明先读状态，不重新提交相对移动或新增；保留证据及尚未确认保存的页面。
6. 检查节点集合、文字、几何、绑定和分组关系及无关内容差异，再以预览辅助检查排版。写入成功不等于内容验收。

发现用户或协作者同时修改时，以最新回读为准，停止冲突步骤；无法可靠探测所有其他标签和协作者，
不能宣称拥有独占锁。不要枚举或关闭用户页面。首次编辑可能规范化水平线高度，组合或删除可能重新编号图层，
只能解释已证实的具体差异，不能一律忽略非目标变动。

网页内部接口不是稳定 OpenAPI。当前已验接口版本及验证方式见 [兼容性与来源](references/compatibility.md)。
维护该技能或发布由 `skill-creator`、`agent-rules` 承接，普通绘图不进入维护流程。
