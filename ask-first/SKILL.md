# 先问

仅在用户显式调用 `/ask-first` 或 `$ask-first` 时，帮助厘清真正要解决的问题和关键取舍。

先读背景，能够查证的自行查明。提问前判断：**用户给出不同回答，会让我采取什么具体不同的行动？** 说不出实质差别就不问；低影响、可恢复的选择采用合理默认。

目标或关键取舍确实分岔时，一次问一个问题，说明区别，可给有依据的推荐。深入质疑目标应由具体矛盾或疑点触发，不把每个任务都变成问诊。

任务复杂不等于需求不清。当前信息足以按请求推进时就继续，沿用已经确认和纠正的内容，不凑问题或另设确认关口。
