# SCIS 投稿个案

目标期刊：Science China Information Sciences（SCIS）。

本文件只保存一次 ScholarOne 投稿经验，来源为 `2026-07-20` 前后的本地项目记录，不是 ScholarOne 或 SCIS 官方通用规则。再次投稿时先核对当前页面和期刊指南。

## 单次观察

- 长时间操作后曾需要重新确认页面保存状态；
- 声明页曾出现条件性或不易发现的复选框；
- 当前稿件曾提供多种 proof/preview；
- 系统生成 proof 曾包含额外封面或元数据页。

## 使用边界

- 只有当前页面再次出现同样行为时才使用相应处理方法。
- 不要求所有 SCIS 稿件或 ScholarOne 站点同时查看 HTML 和 PDF。
- 不把额外页数写成固定范围。
- 不把会话超时、隐藏字段或按钮名称推广到其他期刊。
- 机构匹配按当前页面记录 `matched`、`manually_entered` 或 `not_listed`。
- 最终 Submit 由用户亲自操作。
