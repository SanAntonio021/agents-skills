# 兼容性与来源

本技能说明和脚本为原创实现，依据 CLI 帮助及用户授权的独立画板实测编写，未复制官方技能正文或网页应用代码。
官方技能目录作为行为参考：[飞书官方技能目录](https://open.feishu.cn/.well-known/skills/index.json)。
运行时继续依赖用户安装的 `lark-cli`、`lark-shared` 和 `web-access`；不重新分发其程序或认证信息。

FNV-1a 兼容性指纹，不是安全校验或飞书官方版本号。只读 inspect 可显示实际签名，写入只接受已验证签名。
网页更新导致不一致时重新检查并在隔离画板验证，不能为通过检查直接把当前值加入允许列表。

通过 React 组件读取匹配画板的 `app`，同时校验 `docState.docxToken`、`whiteboardToken`、节点和最新快照。
进入编辑器调用匹配组件的原生入口函数，不用坐标识图；修改走 `commandManager`、文本输入管理器和编辑器事务。
尺寸与端点操作需要动态取得原生事务类：拦截动作分发而不执行，检查节点、序号、undo 状态未变后恢复原方法；
Start/End/UpdateNode 类型和构造函数不匹配即停止。事务关闭使用 finally。

Select 在当前页面也产生 undo 组，因此区分选择事务与内容事务。尺寸及改接包含属性事务和连线几何刷新事务；刷新若重排无关连线，以额外原生事务恢复其原路径。
不能声称所有操作只有一次撤销。公开撤销入口仅限本会话的上一步删除，其后必须核对完整对象恢复结果。

官方整包安装可能再次引入同名技能。接管时清除旧 well-known 安装锁和实体、改由自有仓库维护，
但不承诺阻止用户未来主动重装整包。发现同名入口或来源异常时先处理安装来源，不能自动覆盖本地技能。

未覆盖：独立文本迁入形状、多标签任选索引编辑、分组内曲线手柄、复杂嵌套对象及多人并发编辑的完整语义。标签任意线外固定坐标不是当前人工拖动的保存方式，沿线及上下模式已有入口。
完整回读与预览验收仍然必要，不能只依据页面返回成功。

连线可修改任一端或两端；已有锚点保持，首次绑定采用右中点→左中点。无模板时仅追加一条坐标线，回读其实际ID后重开自有页面，再绑定现有模块；不复制旧模块，不重试未知追加。
刷新绑定会重排同一模块上的其他折线；连接、改接和锚点操作预先克隆旧线的几何与路径属性，刷新后只用原生 UpdateNode 恢复这类副作用。其他字段不能因此变化，保存及重开仍完整核对旧线，不能接受手工路径被自动改写。
恢复判定比较完整原生 baseProps/lineProps，包括首末点、edited 和指定路径状态。复制线两端同时错位时零移动可能只平移错误几何，因此在附件事务中先以 getLineAttachPoint(position) 校正首点，再走原生刷新；以首末点全局坐标核对实际锚点。保存和重开都比较 line_endpoints，绑定ID相同并不证明箭头已经贴到模块上。
折线和正交线拐点用画布坐标输入、转为节点局部坐标，端点沿用 lineProps 的局部点；曲线两个控制点限两端已绑定的线，保存后重开完整原生数据核对。CLI raw 不包含曲线控制点，raw 与页面比较只对此缺省，其他属性仍严格比较；不能用这种缺省替代重开验收。
只有线而没有文本形状的画板，用不实际执行的 LineArrow 探针取得事务构造类，不依赖补建文字形状。
