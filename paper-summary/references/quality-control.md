# 质量检查

总结交付前执行本文件检查。

## 元信息

- 有题目、作者、期刊/会议或来源、年份、DOI/URL。
- 正式期刊论文已执行 LetPub 查询，或写明未查询原因。
- LetPub 查询失败时写明失败原因。
- 预印本的影响因子和中科院分区写 `不适用` 或 `待查询`。

## 内容覆盖

- 覆盖摘要、研究问题、方法、实验或验证方式、结果、结论、局限。
- 覆盖关键 Figure / Table / Equation。
- 关键公式有变量含义。
- 关键实验参数进入表格或专门段落。
- 补充材料与主结论有关时，写入 `## 补充材料与扩展数据`。

## 通信与太赫兹

论文涉及通信系统、太赫兹或硬件链路时，检查是否包含：

- 频段
- 带宽
- 距离
- 调制格式
- 数据速率
- BER / EVM / SNR / OSNR
- 实验平台
- 器件链路
- DSP 或检测算法
- 对比基准
- 硬件限制

## 表述

- 区分作者明确陈述、数据或图表显示、由论文内容推导出的解释。
- 保留作者谨慎措辞，例如 `may`、`suggest`、`indicate`，不要改成确定结论。
- 无法确认的信息写 `未说明`、`待查询` 或 `不适用`。
- 不写主观推荐。
- 不写审稿判决；审稿式判断转 `paper-review`。
