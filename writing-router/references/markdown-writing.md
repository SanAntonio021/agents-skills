# Markdown 正文写法

## 适用范围

本参考用于新写或实质修改 Markdown 正文，规定标题、段落和并列内容的组织方式。具体文体、技术证据和实验记录要求仍由对应技能负责；涉及多个文档的职责、历史归位或引用时，另读 [Markdown 文档组织](markdown-document-organization.md)。

## 段落与重点

除一句话能说完的短答复外，正文按内容分段。每段开头先说明这一段要讲什么，通常用一句短领句或一个短标签，随后给依据、条件或结论。每段只围绕一个中心，下一段推进下一个意思。

默认使用短段落。段落可以连续成文，不必为了排版拆成编号条目。并列事项、步骤、参数或对照确实成组时使用列表或表格；列表中的每一项都围绕同一主题。

一篇文章保持一条清楚的论证主线。背景、例外、验证细节和支线只在读者理解当前内容需要时出现。同一理由不重复解释，也不在结尾重复开头的摘要。

标题用于定位较长内容，不代替段落内的论证。短文档可以只用标题和短段落，不额外增加层级；长文档按内容需要设置标题，每节围绕一个核心意思，避免标题很多但内容重复。
