# paper-search 隔离业务试跑

仅执行两个授权 search 案例，来源为模拟离线记录；未访问真实 Zotero，未联网解析 DOI 或获取 PDF。

| 案例 | 父条目 | 分类 | PDF | 自动设置 | 自动抓取事件 |
|---|---|---|---|---|---|
| search__local_material_handoff | FX000100，新增一次 | 20 / FXCOL020 | FX000101；1 页，863 字节，SHA-256 与源文件一致 | true → false → true | 0 |
| search__metadata_only | FX000100，新增一次 | 20 / FXCOL020 | 0；本任务未请求 | true → false → true | 0 |

任务 A 已读取本地 PDF、BibTeX、publication_index.json，核对题名、DOI、作者与哈希，按 paper-search 交接到 paper-download 本地复制入库。BibTeX 与索引用作题录依据，未作为额外附件导入。文件为模拟输入，version=unresolved；本轮未升级版本。

任务 B 复用环境提供的已核实离线题录，按同一自动抓取检查流程只保存元数据。

源 PDF、BibTeX、索引回读未变化。两任务原生 finally 恢复设置并移除监听，操作注册表 active 已清空。未完成项：无。

## 可核查材料

- requests_responses.jsonl：全部请求、代码、响应及文件回读哈希。
- *_native_request.js、*_operation.json：实际执行代码、操作编号和进程身份。
- *_save_response.json、*_native_readback.json、*_final_state.json、*_logs_final.json：保存、持久化回读与日志。
- local_material_validation.json、local_material_handoff.json：原始材料核对和完成交接。
- import_results.json、final_summary.json：逐案例结果与最终事件检查。

运行限制：这些结果只证明隔离模拟环境中的流程；没有测量真实 Zotero 或外部网站行为。
