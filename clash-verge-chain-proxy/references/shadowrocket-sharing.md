# Shadowrocket 配置分享

处理把 Clash Verge / Mihomo 的链式代理交给 iPhone Shadowrocket 的导入和分享。先判断用户需要完整配置还是纯节点订阅，再决定文件、远程 URL、深链接或二维码。

## 先区分导入入口

- `proxies`、`proxy-groups`、`rules` 和 `dialer-proxy` 组成完整配置时，应从 Shadowrocket 的“配置”页导入 YAML 或远程配置 URL。
- 首页“添加节点 → Subscribe”用于节点订阅，不能把完整 YAML 直接当作普通订阅链接。即使客户端能提取节点，也不承诺保留代理分组、默认路径和链式关系。
- 用户说“订阅 URL”但要求保留完整链时，先用一句话纠正入口；除非重新设计并验证节点级链参数，否则不要声称首页订阅能等价保留分组。

## 生成移动端快照

- 从当前运行配置 `clash-verge.yaml` 生成副本，不修改源配置；记录快照日期、来源和 SHA-256。
- 保留全部 `proxies`、`proxy-groups`、有效 `rules` 和节点级 `dialer-proxy`，不要只导出前置节点或落地节点。
- 只移除明确的桌面环境字段和规则，例如外部控制器、secret、TUN、Windows 进程模式、`bind-address` 和 `PROCESS-NAME`。
- 默认组顺序决定初始选择。需要链式路径时，按“国外网站 → 出口选择 → 落地供应商 → 自动组”核对第一项，但保留仅前置和其他落地路径供切换。
- 静态快照不会跟随 Clash 订阅更新；重新导出时必须替换共享副本并重新验证，不能宣称自动更新。

## 保存前校验

- 用 YAML 解析器重新读取生成文件，确认中文名称、布尔值和多行规则没有损坏。
- 校验代理名和分组名唯一，所有成员引用及 `dialer-proxy` 目标存在，链不存在循环。
- 统计代理、可见分组、隐藏自动组、规则和链式节点数量；与源配置比较，确认除明确移动端字段、进程规则和默认组顺序外没有漂移。
- 读取一条链式节点，核对落地节点的 `dialer-proxy` 指向实际前置节点。
- 使用当前 `verge-mihomo.exe -t -f <file>` 或等价只读语法检查。Mihomo 通过只证明 Hermes/Mihomo 兼容，不证明 Shadowrocket 实机导入成功。

## 交付入口

- 最安全的基础方式是直接发送 YAML，由用户通过“文件”App、AirDrop 或可信聊天工具转到 iPhone。
- 远程配置 URL 也应在 Shadowrocket 的“配置”页添加；不要贴到首页节点 Subscribe。
- 一键深链接为 `shadowrocket://config/add/<URL 编码后的配置 URL>`。深链接只负责安装配置，界面版本可能仍要求点击“使用配置”。
- 可以提供一个普通 HTTPS 引导页，页面只显示“打开 Shadowrocket 并导入”和复制配置地址的兜底按钮。二维码应编码引导页或已验证的深链接，并用本地解码器回读确认。
- 用户要求“不懂操作的人直接导入”时，优先提供一个 HTTPS 引导页或二维码，而不是增加多步手工说明。

## 公网 URL 与长期运行

- 完整 YAML 会暴露节点账号、密码和 UUID。开启公网 URL 前，必须取得用户对分享范围和公网暴露的明确授权。
- 使用 HTTPS、随机且不可猜测的路径；本地服务只响应精确 YAML 路径和必要的引导页，其他路径返回 404。只允许 GET/HEAD，不提供目录浏览、上传或执行接口，不记录含令牌的完整访问路径。
- 临时分享可设置期限和下载次数；用户要求长期使用时，可保存稳定随机路径、配置登录启动并增加单实例守护。长期运行仍取决于电脑在线、用户登录和隧道服务在线，不能承诺电脑离线时可用。
- 提供明确的停止方式：撤销公网转发、删除登录启动项、停止服务。停止操作应能识别普通路径和宿主缓存重定向后的运行路径。
- 不把真实节点、令牌、内网主机名或完整分享 URL 写进项目 Markdown、公开仓库、日志或普通回复。

## 验收与失败判断

- 本地先验证 YAML 路径返回 200、精确字节数、内容类型和 SHA-256；再验证公网 GET、引导页和根路径 404。
- 公网 HEAD 成功不等于完整下载成功；至少执行一次完整 GET 并核对字节数或哈希。
- 在 iPhone 侧核对配置组、默认路径和带 `⛓` 节点的“代理通过”。Windows 上的语法和 HTTP 验收不能替代这一步。
- 如果“配置”页导入后分组存在但链关系为空，先确认没有走 Subscribe、版本是否支持 `dialer-proxy`，再考虑转换为 Shadowrocket 原生 `.conf` 和显式 `chain=`；不在缺少实机证据时直接改协议或丢组。
