# 资料库登记衔接

本约定只在用户已指定或项目已配置资料库时使用；分类、路径及确认要求来自该资料库的 README、项目规范和 AGENTS，不在通用技能内写本机路径、人员、成果或指标。

## 归属与登记

- 项目自产内容及交付要求随包提供的依赖按项目结构保存；一般外部参考资料由 Zotero 管理。跨主题查找通过登记关联，不为每种材料类型复制一份。
- 沿用现有人工主登记及稳定编号。文件登记描述实际位置、类型、主题、所属主体、版本和确认状态；引用登记关联文件编号、具体章节/页码/批次、可支持的内容、条件及核实状态。机器迁移清单是操作依据，不另当一套日常维护的登记。
- 文件发生移动时保留编号，更新实际路径及受影响的引用；新文件再分配新编号。缺失记录不能凭旧路径重造另一个身份，须先查来源映射。
- 不把文件名、修改时间、最高版本号、哈希一致或用户确认正文当作实际提交、证书核验或实测依据。未知版本或引用状态标待核实，后续使用时核对并回填。
- 已提交材料包内承担提交上下文的重复附件保留，只有核对内容后才登记为相同材料副本；不能仅凭同名去重。散落副本的退役仍受具体授权和恢复检查约束。
- 既有飞书、Zotero 等登记继续承担原有职责，通过标识或链接关联，不默认复制在线正文或重建其数据库，不扩大访问权限。
- 用于工作区研究、设计或选型的正式论文、标准、厂家资料及无存储限制的供应商技术资料归 Zotero；分类按 [`zotero-workspace-library`](../../zotero-workspace-library/SKILL.md)。Zotero 条目不依赖项目本地路径定位附件；同一资料由多个项目使用时通过多个集合关联，不按项目复制附件。
- 项目自产代码、数据、仿真、实验记录和报告留项目。外部参考 PDF 不作为项目本地长期副本；既有文件原样保留，历史迁移只在用户明确授权的专项任务中处理。资料的限制或许可状态不明时不上传 Zotero。
- 飞书选型表只登记进入比较、准备采购或已采用的器件，不要求覆盖全部查阅资料。飞书中出现的型号可引用对应 Zotero 手册条目；本技能只检查提示，不直接改飞书 Base。

## 执行与验收

1. 先展示实际来源、目标、登记变更、依赖、清理范围和恢复方式；用户明确要求清单确认时，在授权覆盖前不执行搬动或关联清理。复用已有准确授权，不反复确认同一范围。
2. 迁移仍走主技能的完整性、哈希、Git 恢复、引用修复及真实使用检查。材料内容未知可登记待核实；归属或依赖不明、文件锁定、未下载完整、特殊路径未解析属于对应迁移的未完成项，不以待核实标签绕过保护。
3. 验收原文件处置、编号唯一性、实际路径可达、引用编号存在、正式入口无过程目录依赖；按真实任务验证一次跨目录查找。有外部器件手册时，核对 Zotero 分类/条目/附件及飞书已有型号引用关系；项目内本地资料只核对自产材料或既有文件，不为新规则制造 PDF 副本。Zotero 写入按条目回读，未写入或缺失只报告待处理。核验失败保留原件和恢复材料。
4. 分别报告登记完成、迁移完成、内容核实及旧位置退役状态。普通任务完成不自动归入资料库；由项目约定的收尾入口承接。
