# 算术与流水线

先写清每个量的有无符号、总位宽、小数位、数值范围和单位。明确中间结果需要全精度还是有意截断；输出采用回绕、饱和或报错由接口契约决定。

- 检查操作数扩展、表达式的上下文位宽、无尺寸常量、移位及比较的 signed/unsigned 规则。不要假定赋值目标较宽就能修复所有中间截断。
- 按数学范围推导乘加位宽；混合有符号和无符号先明确转换。舍入方式、负数处理和饱和边界均要进自检，不套用固定的“额外加一位”公式。
- 参数检查覆盖最小位宽、深度为 1、非二次幂深度、计数上限和 `$clog2` 产生零位宽等情况；仅支持的参数组合才声明有效。
- 流水线插级同步处理数据、valid、标记、地址、ID 和控制。延迟按实际接受与输出事件核对；有停顿的流水线不能把固定周期延迟当作无条件契约。
- 状态机说明进入、保持、退出和异常输入行为；复位期间输出与下游观察到的有效状态必须一致。不要将未知 X 无条件当作 don't-care 以掩盖错误。

资源推断与综合属性按需读取 vivado-synth；仿真语言支持以当前工具为准。参考本机 Vivado 对应版本 UG901 的 HDL 编码和表达式说明，算术期望值由独立模型计算，不能复制 DUT 的截断错误。
