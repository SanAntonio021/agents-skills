# 科研汇报中文表达

本文件是随技能提供的通用表达规则，不依赖作者的个人词表。写提纲和逐页正文前读取，展示前结合实际句子检查。已有清楚自然的文字保持原样。

## 先核对事实，再修改表达

- 保留数字、单位、比较条件、专有名词、因果关系和完成状态。软件验证、仿真结果和实测结果分别表达。
- 按“具体问题—本次工作—观测结果”组织信息；只有理解结果需要时才补背景，不强求每页都有三栏。
- 进展页标题先点明真实项目名称，再用三个 ASCII 空格连接本页主题；同一行中项目大标题加粗，本页小标题按 PowerPoint 字号档缩小两次、不加粗。用户确认的项目名称优先，不用会话标题或自行缩写替代。红条概括一项当页结果，正文补充必要条件。删除三处重复的同一结论。
- “明显提高”“效果良好”“取得突破”须有材料中的比较证据。没有定量结果时如实说明已完成的步骤，不补造数字。
- 删除空泛的开场、重要性评价和收尾升华。试删一句后，如果对象、方法、条件和结论仍清楚，就不换成另一句套话。
- 不凭字数机械压缩，也不为了避免重复而更换同一专业术语。真实限制、否定关系和条件应保留。
- 后续行动只写用户或项目记录已确定的内容，集中在最后一页；助手新建议需先确认。
- 进展页直接写当前方法、工作和结果，不复述对话、改稿及放弃方案的经过，也不罗列未做事项。研究方法改变本身是有证据的科研进展时，说明改变及其结果。

## 必要信息判断与全文检查

先把本页对象、测试条件、方法及结果写准确，再统一检查标题、总结、正文、表头、括号、图注和表注。页面已经交代的信息不再重复；来源核查过程、改稿过程及与本页结论无关的未完成事项不进入页面。仿真、离线、实测或原型状态在对应结果处说明，解释数据所需的条件、比较基准和假设尽量集中说明一次。

1. **试删后指出具体影响。** 对术语释义、括号、读图提示、页底补充和限制句，问：删掉后，会把哪项数据、条件、对象或结论理解错？能指出与本页实际主张有关的误读才保留。“更严谨”“怕别人误会”不足以保留。“项目照片”等无信息标签可删；正文已交代后重复出现的“结果为暂算”“尚未验证”等说明可删。会改变数值含义的“估算”“假设损耗”、采集次数及必要测量条件仍须保留，不把这些词设成一律删除的禁词。听众理解当前工作所需的背景照常保留。
2. **先修正主句，再考虑补充。** 正面写明对象、范围和状态，能用简短条件、单位或图例说明的就放在对应位置；不要先写宽泛结论再用“不是……”“不代表……”补救。跨页确需重申的条件可以重复，必要否定也可以保留。
3. **每句话提供信息。** 把标题、总结、图表和正文作为同一页合起来读；状态或条件已有清楚表达，就算已经交代，不要求在每种载体上再写一次。日期、统计方法和计算定义在同组结果中通常只交代一次，跨页确需重申时再保留，不在同页标题、正文和图注中重复；历史实测的时期仍须在对应结果或明确关联的来源说明处保留，不能因精简而变成当日新测。删除没有新增信息的重复解释、机械栏目及改稿过程；后续行动统一末页。不要用另一句套话替换，也不机械转存备注。仅供讲解的细节可按需放备注，复现细节留在实验记录，判断结论必需的信息仍在页面。短段落、少量条目和留白可以直接保留，不为显得充实而补文字。
4. **检查最终全文。** 从完成的 PPT 提取全部可见文字，连同图片内文字逐页阅读，而非只查被指出的一句或某类关键词。核对删改后对象、数字、单位、比较条件、因果和状态仍准确，再看实际渲染。内容检查和文件/排版检查分别记录；词表零命中不能证明表达合格。

例如，图中虚线表示发射端中频板的输入参考功率，可标“虚线：发射端中频板输入参考功率 −7 dBm”；不必再补“不是中频板实测线性限”。若在解释误差棒，则“误差棒：样本标准差，n = 3”直接影响读图，应保留。数值仅用于演示表达方法，不能套入其他实验。

进展页保留理解结果所必需的采样率、输入功率、比较基准及仿真或实测状态；换线前关闭输出、程序启动与恢复等执行提醒留在操作单。仅专门讲解操作规程的页面保留相关提醒，“实验步骤”页不自动照搬操作单，只展示本次确定的顺序与方法。“完整二维扫描为选做”等可选安排默认不写，已确定任务进入末页。

副标题写清具体对象和本页主题，例如“示波器采集窗口对比”，不为简短省掉理解所需的设备或研究对象。对象必须来自材料，不猜测；项目大标题仍负责说明所属项目。

## 总览页：工作缘由与实际推进

像向导师说明今天的工作一样写，先让读者知道在研究什么，再说今天具体讨论、比较、修改或验证了什么，以及已有结果或当前进度。每项通常用一至两句，按材料决定是否需要背景，不为套齐“目标—行动—结果”补造原因或结论，也不为压成一行省掉研究内容。

- 论文与方案进展要交代研究对象、确定的技术问题或实验思路。“确定验证路线、完成引言”“修订方案、更新文档”可以说明进度，但不能代替具体内容；按材料说清路线怎样安排、论文准备考察哪些问题，修改了哪项论述。写稿进度放在这些内容之后，需要时简短说明。
- 用具体对象和普通动词写清工作，例如“比较候选频率源”“整理已有参考文献”“核对结果与引用”。“归集、框架、支撑”等抽象词没有增加信息时，改成当前实际动作或删除；不凭关键词替换专业术语，也不将本次措辞设成所有语境的禁词。删除反复的“围绕……完成……”，保留必要的因果和比较关系。
- 一项工作的多个分析页在总览合并说明，重点放在研究推进。有证据确认的工作直接陈述；方案、仿真、离线测试和实测按实际状态表达。影响含义的条件在主句中简短交代，详细参数放对应结果页；避免重复结论、堆叠谨慎措辞和罗列未做事项。

以下为虚构示例，只示范表达方法，不作为用户成果或固定句式：

- 原句：“变频论文：确定验证路线，完成引言。”假定材料支持商用通信设备复用、驱动条件与变频性能研究及两阶段实验，则可写：“讨论了如何复用商用通信设备，通过外部混频器将信号搬到更高频段。论文将考察驱动条件、变频损耗、杂散和业务传输性能，已据此修改引言，并确定先验证现有器件、再开展高频通信的两阶段实验。”
- 原句：“双向通信论文：完成文献归集。”假定材料支持功率与自干扰讨论及既有文献整理，则可写：“讨论提高发射功率后，自干扰和接收前端非线性会怎样影响通信，明确实验需要同时考察可用的频率和功率范围。整理了已有参考文献和 PDF，继续讨论引言。”

## 页面检查与独立安装基础检查

- 总览按上节检查缘由和实际推进。用户确认的参考条目保存在当前汇报项目记录中，复用其因果表达方式，不把其中的对象、指标和状态套入其他任务。

- 有比较结果时先讲结果；开发类工作说明实现的关键实验操作，方法类工作说明怎样验证。只说修订了文档时，按材料说明具体方法；不把页面写成按钮或功能逐项介绍，也不补写没有依据的价值、性能提升。准确且有用的功能清单和完成状态仍保留。
- 小标题须指出具体对象或问题；“统一控制与记录”“两端同时观察”等标题若含糊或与正文重复，就具体化或删除。无需分组时不补栏目，不为填版面加字；总结条与正文各自提供信息。
- 下一步每项按“项目总体目标 → 当前待解决的问题 → 下一步行动及目的”组织，讲清为什么做、具体做什么、用来解决或确认什么。总体目标可简短承接，不必照抄首页；围绕一个主要目标保留必要步骤和先后顺序。只写有材料依据、已确定的安排，不补造任务或预期结果，不把行动目的写成已取得的成效。
- 交付前检查末页是否只剩“继续测试、完善程序、整理记录”等动作清单；若无法看出行动与项目目标、当前问题的关系，按已确认材料补清前因后果，不堆叠无关动作，也不擅自删掉已确认任务。末页由智能体随整套制作完成，不增加单独讨论或确认环节。
- 独立安装时，按以上规则及前节完成基础检查：先核对事实、状态和必要条件，再试删空话、多余解释和重复；机械完成句按真实内容组织，清楚自然的原句不改。不禁用“完成、更新、修订”等词，不为自然表达改变术语或补造事实。通用规则可用时直接读取，不在此维护完整副本。

## 用词检查表

这些是需要结合语境检查的表达，不是禁用词。建议列提供改写方向，不执行全文替换。

| 不建议 | 建议 | 例外 |
|---|---|---|
| 赋能；助力 | 写明支持什么工作、解决什么问题 | 引用原文、机构固定口号 |
| 至关重要；彰显 | 写具体作用或观察结果；无信息可删 | 引用原文 |
| 深入探讨 | 分析；研究；讨论，并说明对象 | 用户要求保留的标题 |
| 闭环 | 写明完成了哪些操作和验证 | 控制理论、反馈控制系统中的正式术语 |
| 沉淀 | 形成；保留；积累，并说明产物 | 化学沉淀、材料沉积等专业语境 |
| 聚焦 | 围绕；关注，或直接写研究对象 | 光学聚焦、成像聚焦 |
| 口径 | 定义；统计方式；标准 | 天线口径、波导口径 |
| 对齐；拉齐 | 统一；保持一致 | 相位、时间、符号对齐；版式对齐 |
| 落地 | 实施；实现；部署，并说明完成程度 | 飞行器着陆等字面含义 |
| 维度 | 方面；角度，或直接写比较变量 | 空间、矩阵等数学或物理维度 |
| 颗粒度 | 细化程度；详细程度 | 专业领域已有明确定义时按原文 |
| 收口 | 完成；定稿；收尾 | 工艺操作的字面含义 |

## 表达示例（虚构，仅示范文风）

原句：本次工作聚焦性能优化，通过深入探讨实现技术闭环，为后续研究奠定坚实基础。

假定记录实际只支持“在相同输入功率下比较两组滤波参数，第二组带外噪声较低，尚未测误码率”，则可写：

在相同输入功率下比较了两组滤波参数，第二组的带外噪声较低。

这句话只讨论带外噪声，无须另补“尚未测量误码率”。若正文要进一步判断误码性能，缺少误码率测量就会影响结论，须保留这一限制；只有项目已确定误码率测试安排时，才把该安排写入末页。

原句：完成扫描程序开发并通过离线测试。当前为离线验证，尚未连接真实仪器。

可写：完成扫描程序开发并通过离线测试。

“通过离线测试”已准确说明完成程度；已确认的实机测试安排放末页，不在成果页重复强调没做什么。

不得把这组示例条件或结论移入用户的真实汇报。

正文已写“有用信号接物理 LO 口，泵浦经正交网络接 I/Q 口”时，可删除后面的“图中 IF、LO 表示信号角色”。具体接法已经说明，补充释义不再增加本页信息；需要口头讲解时放备注。若缺少具体接法就会混淆端口，则先保留能消除歧义的必要说明，不按关键词一律删除。

## 润色执行与内容验收

写提纲和页面正文前，按本文件执行表达检查。已安装 `writing-router` 时，从实际安装目录读取 `references/common-quality.md` 与 `references/ai-smell-catalog.md`，执行其通用表达检查；不重新进入写作路由或改变本技能的内容选择、确认流程。未安装或参考文件不可读时，使用随附规则中的基础检查，不要求额外安装；在已有过程记录中如实记明实际读取与采用的路径。通用规则只维护在 `writing-router`，随附文件不复制完整目录。

起草与最终交付前，自动执行通用润色与页面检查。同一批内容、材料和规则未变化时复用已完成的检查；修改后检查变化内容及相关上下文，最终仍通读全稿。先检查整句与前后页是否好懂，再结合词表及例外检查用词；不能只读规则或仅凭词表无命中就声称润色完成。

个人词表是可选增强：用户提供文件或项目根目录存在 `汇报词表.md` 时读取；已安装并配置好 `writing-router`、`style-vocab` 时，可沿用其检查流程。不依赖作者的私人词表和本机路径；没有个人词表时仍完整执行随附规则。

像向导师说明工作一样写具体问题、行动和结果，避免检查报告式栏目、改稿经过及对未做事项的罗列。专业术语、必要背景和影响结论的限制按实际语境保留，不批量删否定句，也不为顺口改变事实。具体取舍和示例统一维护在随附中文规则中。

交付前从最终 PPT 提取全部可见文字，按页通读标题、总结、正文、表格及图注，结合实际图件执行必要信息判断；图片内的文字直接看图核对。逐项检查页内名称能否明确指向具体设备、部件、端口或操作，不把标题、表头和短图注排除在检查外；名称与简称的通用规则沿用已加载共同质量规则，不在本技能重复维护。修改后检查相关上下文，并复查最终渲染；删并页、增页或调序后同步目录、交叉引用、可见页码和总页数。在已有过程记录中分别留下内容表达检查与文件/排版检查结果，简记实际删改及必要保留项。词表零命中、文件有效或图文不溢出都不能代替全文检查；未完成内容检查时不能笼统报告“检查通过”。
