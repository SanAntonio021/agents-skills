# 通信与太赫兹论文信息表

当论文涉及通信系统、太赫兹、毫米波、MIMO、器件、实验链路、调制、DSP、信道建模或硬件平台时，额外提取本文件字段。

## 专用结构

```markdown
## 通信与太赫兹专用信息

### 系统或链路结构

### 频段、带宽与传输距离

### 调制格式与数据速率

### BER / EVM / SNR / OSNR 等指标

### 器件与实验平台

### 信道、阵列或传播模型

### DSP / 算法流程

### 对比基准

### 硬件限制

### 可复现性
```

## 指标字段

优先用表格整理以下字段。原文没有说明时写 `未说明`。

| 字段 | 记录方式 |
|---|---|
| 工作频率 | 写频点或频段，例如 `115 GHz`、`220-330 GHz` |
| 带宽 | 区分模拟带宽、信号带宽、占用带宽 |
| 传输距离 | 区分无线距离、光纤距离、总链路距离、链路预算外推距离 |
| 速率 | 区分线速率、聚合线速率、可达信息速率、净信息速率 |
| 调制格式 | 写 QPSK、16QAM、64QAM、OFDM、单载波等 |
| 编码 | 写 FEC/LDPC/HD-FEC/SD-FEC、码率和判决门限 |
| BER | 标明 pre-FEC、post-FEC 或未说明 |
| EVM | 写数值、单位和测量条件 |
| SNR/OSNR | 写定义、带宽口径和测量位置 |
| 器件 | 写源、倍频器、混频器、放大器、天线、光电器件、ADC/AWG |
| DSP | 写同步、均衡、相位恢复、频偏恢复、MIMO 检测等 |
| 对比基准 | 写作者比较对象和表格口径 |

## 写作要求

- 系统、链路、器件和测量结果常作为主语。
- 先写信号链：源信号、调制、变频、链路、接收、DSP、测量指标。
- 对 MIMO 论文，写清通道数、信道矩阵或检测方法、训练序列、均衡器和串扰处理。
- 对 IQ / ISB / sideband 相关论文，写清分离依赖频域隔离、I/Q 幅相误差、IRR，还是 2x2 信道估计和均衡。
