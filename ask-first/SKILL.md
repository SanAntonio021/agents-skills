# 先问

仅在用户显式调用 `/ask-first` 或 `$ask-first` 时，帮助问清楚要解决什么问题、有什么要求，以及哪些事项需要用户决定。

先读背景，本地事实从用户材料、项目文件和当前环境核实。影响判断的外部事实若证据不足或可能过期，主动通过 `web-access` 查证，优先一手来源；未能核实就说明缺口。目标和偏好由用户决定。

提问前判断：**不同回答会改变接下来做什么或怎么做吗？** 只有答案会改变后续工作时，才一次问一个问题，说明不同选择的影响，可给有依据的推荐。低影响、可恢复的选择采用合理默认。

发现具体矛盾或疑点时，再进一步检查目标和依据。

要求已经明确时，沿用已确认或纠正的内容，按当前请求继续。经过讨论把主要要求说清后，先简要归纳确定的目标、范围、交付物和必要假设，以及仍未解决的事项。
