# Word 成品检查

按本次要求、指定模板或采用的默认样式检查内容和版式。静态属性正确不代表渲染正确，截图正确也不代表格式与可编辑性符合要求。

| 项目 | 检查内容 |
|---|---|
| 字体 | 正文、标题、表格与页眉页脚的中文/西文、字号、颜色、主题和直接格式；发现意外回退时定位原因 |
| 段落 | 首行、悬挂与左右缩进、行距、段前段后、对齐；表格单元格不要意外继承正文首行缩进 |
| 表格 | 每张表的表头、列宽、边框、字体、水平和垂直对齐，以及跨页可读性 |
| 页眉页脚 | 各节可用宽度、距边、对象位置；检查越界、遮挡、拉伸和裁切 |
| 分页 | 逐页检查缺字、重叠、公式/表格断裂、非预期空白页、编号与页数约束 |
| 实际打开和渲染 | 记录本轮采用的应用；Word 原生检查时保留只读打开、PDF 导出和 Word/PDF/PNG 页数一致性证据 |

使用一个适合目标应用的真实渲染器，智能体逐页检查。已有模板或渲染基线可作比较；没有时按当前要求和可读性判断，不要求用户先批准栅格基线或逐页签字。

按实际检查记录通过、问题或未验证及必要证据路径，修复影响交付的问题。无须为每次任务新建固定字段的验收状态机。明确要求 Word 原生验证时，其他渲染器不能替代该结论；不能安全运行时如实说明未验证部分。
