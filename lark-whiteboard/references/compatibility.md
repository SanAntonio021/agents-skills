# 兼容性与来源

本技能说明和脚本为原创实现，依据 CLI 帮助及用户授权的独立画板实测编写，未复制官方技能正文或网页应用代码。
官方技能目录作为行为参考：[飞书官方技能目录](https://open.feishu.cn/.well-known/skills/index.json)。
运行时继续依赖用户安装的 `lark-cli`、`lark-shared` 和 `web-access`；不重新分发其程序或认证信息。

2026-09-30 开发环境 CLI 为 1.0.94，浏览器 Proxy 为 protocol v2。页面内部命令签名 `49cce4b3` 是指定命令函数源码的
FNV-1a 兼容性指纹，不是安全校验或飞书官方版本号。只读 inspect 可显示实际签名，写入只接受已验证签名。
网页更新导致不一致时重新检查并在隔离画板验证，不能为通过检查直接把当前值加入允许列表。

通过 React 组件读取匹配画板的 `app`，同时校验 `docState.docxToken`、`whiteboardToken`、节点和最新快照。
进入编辑器调用匹配组件的原生入口函数，不用坐标识图；修改走 `commandManager`、文本输入管理器和编辑器事务。
尺寸与端点操作需要动态取得原生事务类：拦截动作分发而不执行，检查节点、序号、undo 状态未变后恢复原方法；
Start/End/UpdateNode 类型和构造函数不匹配即停止。事务关闭使用 finally。

Select 在当前页面也产生 undo 组，因此区分选择事务与内容事务。尺寸及改接包含一个属性事务和一个连线几何刷新事务；
不能声称所有操作只有一次撤销。公开撤销入口仅限本会话的上一步删除，其后必须核对完整对象恢复结果。

官方整包安装可能再次引入同名技能。接管时清除旧 well-known 安装锁和实体、改由自有仓库维护，
但不承诺阻止用户未来主动重装整包。发现同名入口或来源异常时先处理安装来源，不能自动覆盖本地技能。

未覆盖：独立文本迁入形状、任意折线拐点、线外任意标签坐标、多标签选择编辑、改接起点、复杂嵌套对象及多人并发编辑的完整语义。
完整回读与预览验收仍然必要，不能只依据页面返回成功。

本次创建试验不替代已有节点编辑接口的独立验证。

CLI 对批次外端点返回 2890002（attached object id not found），所以追加入口拒绝这种输入。
锚点通过 attachProps 克隆更新，再以原生命令刷新几何，不写 nodeMap。
零位移可能保留旧几何缓存，锚点刷新采用模块向右 1 px 再原位返回的原生移动；最终模块坐标必须不变，连线几何必须回读并预览核对。
此刷新在隔离板实际验证为 3 个内容事务；任一步异常后保留结果不明状态，不自动重放整组，也不在 finally 中盲目追加回移。
新增连接或改接后也须核对实际几何，不能仅凭绑定 ID 正确判断完成。
