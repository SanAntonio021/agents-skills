# 中文通用文风

| 不建议 | 建议 | 例外 |
|---|---|---|
| 过载 | 射频链路描述中，按实际状态使用“增益压缩”或“饱和”，避免笼统使用“过载” | 原文引用、器件或仪器固定名称及其他领域的专业用法；不将“压缩”和“饱和”视为同义词 |
| 压缩差、压缩差额 | 直接写“饱和输出功率与 P1dB 的差值” | 需要引用原文或讨论压缩特性时按原始资料表述 |
| 泵浦 | 混频器技术交流、方案及仿真说明中优先用“本振驱动”“驱动信号”“IF口驱动”；首次说明“IF口输入本振驱动信号，原LO口输入待变频信号” | 引用原文、讨论非线性机理或参数放大时按语境保留；其他领域的专业用法不受此偏好限制，不作全局替换 |
| 通视条件 | 实施方案说明安装条件时，写“两端之间是否有遮挡” | 施工规范、专业施工文件、原文引用及其他文体中的专业用法 |
| 敷设线缆 | 实施方案说明安装操作时，写“布置线缆” | 施工规范、专业施工文件、原文引用及其他文体中的专业用法 |
