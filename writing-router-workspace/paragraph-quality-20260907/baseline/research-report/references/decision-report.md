# 决策报告

这份规则只在 `mode=decision_report` 时读取。它只放宽证据型报告对“建议”的限制，不放宽事实、来源和完成状态要求。

## 建议链

每项建议内部记录：

| 字段 | 内容 |
|---|---|
| 决策对象 | 谁要决定什么 |
| 依据 | 前文哪条事实或判断 |
| 建议 | 采用、比较、验证、暂缓或排除什么 |
| 条件 | 预算、指标、时间、接口、证据门槛等 |
| 风险 | 选择后的主要代价或失效条件 |

正式正文不用展示这些内部标签，但读者应能看出这条链。

## 写法

- 先给判断，再给建议；建议不重复整段背景。
- 有明确优先级时写出比较依据，不用“综合考虑”“稳步推进”代替。
- 证据只支持验证时，写“先验证”，不能写“立即建设”。
- 多个选项条件不同，就按条件分支，不强行给唯一答案。
- “暂缓”需要具体触发条件；“持续关注”不是建议。
- 建议不得改写成已经批准、已经实施或已经产生效果。

## 与证据型规则的关系

[report-contract.md](report-contract.md) 中关于内部编号、未闭合证据、虚构元数据、事实与判断混写的限制继续有效。只有“正式报告不得出现建议或行动内容”这一项由本文件替代。
