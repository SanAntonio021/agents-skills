# PowerPoint 手动粘贴文本

适用于 Windows 桌面版 PowerPoint：用户已经把文本插入光标放进现有文本框，希望从
Codex、浏览器或其他富文本来源粘贴文字，同时沿用光标位置的字体、字号、颜色和段落格式。

## 先看现场证据

按下面顺序判断，不要先套用 Word 的经验：

1. 确认文本框内出现了文本插入光标，而不是只选中了文本框对象。只有进入文字编辑状态，
   纯文本才有明确的目标文字格式可继承。
2. 记录复制来源，并读取当前 PowerPoint 实际显示的粘贴选项。来源同时提供 HTML 和
   Unicode 文本时，普通 `Ctrl+V` 可能优先采用带格式内容。
3. 以当前菜单或截图为准。粘贴选项会随复制来源、剪贴板格式、光标位置和 Office 版本变化；
   某个选项没有出现，本身不等于 PowerPoint 故障。
4. 再检查用户要的是一次性粘贴、经常使用的原生命令，还是强行改写 `Ctrl+V`。这三种需求
   在 PowerPoint 里不是同一个设置。

## 三个常见选项的含义

当菜单只有下面三项时，它没有提供纯文本粘贴：

| 菜单项 | 实际含义 | 是否满足“沿用当前文本框文字格式” |
|---|---|---|
| 使用目标主题 | 让内容适配目标演示文稿的主题；仍可能保留来源结构或直接格式，不保证与光标处文字格式完全相同 | 不保证 |
| 保留源格式 | 尽量保留复制来源的 HTML/文字格式 | 不满足 |
| 粘贴为图片 | 把内容作为图片放入，文字不再可直接编辑 | 不满足 |

不要把“使用目标主题”解释为“只保留文本”，也不要因为菜单缺少“只保留文本”就让用户修复
或重装 PowerPoint。

## 最接近目标的原生操作

### 一次性可靠操作

1. 把文本插入光标放在目标文本框的正确位置。
2. 按 `Ctrl+Alt+V` 打开“选择性粘贴”。
3. 选择“无格式 Unicode 文本”；部分版本或来源可能显示为“无格式文本”。
4. 确认粘贴。

这条路线去掉来源格式，使文字采用插入点或所在段落的目标格式。若文本框为空、光标附近存在
混合格式，或占位符本身没有设定目标字体，结果会取决于该位置的段落/占位符默认值。要得到
微软雅黑，先确保插入点所在文字或占位符已经是微软雅黑；微软雅黑不是剪贴板层面的强制设置。

### 经常使用

可在“文件 → 选项 → 快速访问工具栏”中，从“所有命令”查找并添加“粘贴并只保留文本”或
“只保留文本”（名称随 Office 版本可能不同）。这提供原生的一键入口，但不会把 `Ctrl+V`
重新绑定为纯文本粘贴。若当前版本没有该命令，继续使用 `Ctrl+Alt+V`。

### 已经按了 Ctrl+V

粘贴后菜单若出现“只保留文本”，可以直接选；若实际菜单没有该项，PowerPoint 没有一个设置
能强制把它补进本次动态菜单，改用上面的“选择性粘贴”或快速访问工具栏入口。

## 设置与快捷键边界

- PowerPoint 的“文件 → 选项 → 高级”可以控制是否显示粘贴选项等行为，但没有 Word 那组按
  来源指定默认粘贴方式的下拉设置，不能把普通 `Ctrl+V` 全局设为“只保留文本”。
- 修改主题字体或占位符字体可以让新文字默认使用微软雅黑，但不能阻止富文本 `Ctrl+V` 带入
  来源直接格式；它不是同一个问题。
- Windows 桌面版 PowerPoint 的 `Ctrl+Shift+V` 用于粘贴格式，不是纯文本粘贴，不要把它推荐
  为“只保留文本”的快捷键。
- 用户要求只用 PowerPoint 原生功能时，不主动转向 AutoHotkey、PowerToys、剪贴板工具或宏。
