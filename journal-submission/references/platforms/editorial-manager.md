# Editorial Manager

产品归属：Aries Systems。Aries 于 2018 年被 Elsevier 收购，但 Editorial Manager 服务多个出版社、学会和机构，不能写成“Elsevier 投稿系统”。

本资料基于 Aries 官方帮助，最后核对 `2026-07-25`；尚未经过本机真实投稿页面验证。第一次实际使用时必须逐页识别并更新带日期的验证记录。

## 官方通用流程

官方帮助列出的核心步骤可包括 Article Type、Attach Files、General Information、Review Preferences、Additional Information、Comments 和 Manuscript Data。出版物和文章类型可以配置步骤、字段和顺序。

通用提交核心：

1. Build PDF；
2. View Submission；
3. Approve Submission；
4. 按页面完成后续确认。

Approve 和后续确认属于最终提交动作，必须由用户亲自操作。

## 机构规范化

Institution Name Normalization 是可配置功能。站点可以提供规范机构匹配，也可能允许自由文本。按当前页面记录：

- `matched`
- `manually_entered`
- `not_listed`

不要假设每个 Editorial Manager 站点都有 Ringgold 或相同机构标识符。

## 首次真实页面验证清单

- 站点主机名、出版组织和目标期刊；
- 实际页序和必填字段；
- 文件类型、Build PDF 和 View 要求；
- 机构匹配方式；
- 最终按钮原文和确认步骤；
- 页面是否有 Reviewer PDF、声明、审稿人或费用字段。

验证前不得把本文件标成已实测。
