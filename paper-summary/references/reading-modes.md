# 阅读模式

本文件用于选择单篇论文总结的阅读深度。默认只处理一篇论文；多篇文献筛选、代表作调研和综述写作转 `research-lookup` 或 `writing-router`。

## 模式选择

| 用户需求 | 使用模式 | 输出重点 |
|---|---|---|
| 快速看一下、先了解 | 快速摘要 | 题目、研究问题、方法一句话、主要结果、局限 |
| 总结这篇、整理文献笔记、做论文卡片 | 完整解析 | 元信息、术语、研究问题、方法、实验、结果、图表、公式、局限 |
| 看公式、图表、实验条件、关键参数 | 技术细节提取 | 公式变量、输入-处理-输出、实验设置、参数表、图表证据 |
| 审一下、评价一下、判断可信度 | 批判性分析 | 先完成事实总结；审稿式判断转 `paper-review` |

## 三遍阅读法

完整解析模式可使用三遍阅读法。

1. 第一遍看题目、摘要、结论、章节标题、图题和表题，确定论文主线。
2. 第二遍看方法、实验设置、关键公式、结果图表，提取可核验参数。
3. 第三遍看局限、补充材料、数据可用性、可复现性和与用户研究方向有关的内容。

快速摘要模式不强制三遍阅读。用户要求“完整总结”“技术细节”“图表公式不要漏”时启用完整解析或技术细节提取。

## 论文类型

先判断论文类型，再决定总结重点。

| 类型 | 总结重点 |
|---|---|
| 理论论文 | 假设、模型、公式推导、变量定义、适用范围 |
| 实验论文 | 实验平台、测量条件、样品或链路、结果指标、误差来源 |
| 系统论文 | 系统架构、信号链路、关键器件、算法流程、端到端指标 |
| 综述论文 | 分类框架、文献范围、比较维度、作者给出的趋势和限制 |
| 数据集或工具论文 | 数据来源、工具流程、输入输出、验证方式、可复现材料 |

## 笔记可读性

总结完成后检查：几周后只看这份 Markdown，是否能看懂论文解决了什么问题、用了什么方法、实验怎么做、关键结果来自哪里。

方法部分按 `输入 -> 处理过程 -> 输出结果` 写。不要只列公式名或算法名。
