# 中文通用文风

| 不建议 | 建议 | 例外 |
|---|---|---|
| 赋能 | 用于；支持 | 引用原文、政策标题原文 |
| 助力 | 支持；促进 | 引用原文、机构固定口号 |
| 闭环 | 完成验证；形成流程 | 控制理论、反馈控制系统中的正式术语 |
| 沉淀 | 形成；保留；积累 | 化学沉淀、材料沉积等专业语境 |
| 此外 | 同时；另外；可删 | 结构清晰且确需并列过渡 |
| 至关重要 | 重要；关键 | 引用原文 |
| 彰显 | 表明；反映 | 引用原文、正式标题原文 |
| 凸显 | 显示；突出 | 视觉显示、图形突出显示的字面语境 |
| 深入探讨 | 分析；研究；讨论 | 章节标题沿用用户原文时临时保留 |
| 服务于 | 用于；支撑 | 组织职责、公共服务语境 |
| 聚焦 | 围绕；关注 | 光学聚焦、成像聚焦等专业语境 |
| 口径 | 统计方式；定义；标准 | 天线口径、波导口径、aperture 对应译名 |
| 边界 | 适用范围；限制；前提 | 边界条件、吸收边界等物理或数学术语；SKILL.md 的“边界”节标题 |
| 对齐；拉齐 | 统一；保持一致 | 相位对齐、时间对齐、符号对齐等信号处理语境；版式对齐 |
| 颗粒度 | 细化程度；详细程度 | — |
| 收口 | 收尾；定稿；完成 | 机械或工艺收口的字面语境 |
| 落地 | 实施；实现；部署 | 字面落地，如飞行器着陆 |
| 拆解 | 分解；分析 | 硬件拆解的字面语境 |
| 维度 | 方面；角度 | 空间维度、矩阵维度、天线阵列维度等数学或物理用法 |
| 锚点；锚定 | 基准；参照 | 网页锚点、机械锚固的字面语境 |
| 体感 | 直观感受；实际观感 | 体感温度、体感交互设备 |
| 台账 | 清单；登记表；记录 | 财务、资产、安全生产等制度规定的正式台账名称；引用文件名或制度原文 |
