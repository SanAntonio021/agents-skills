# 中文申报书文风

| 不建议 | 建议 | 例外 |
|---|---|---|
| 抓手 | 措施；路径；任务 | 引用政策原文 |
| 打造 | 建设；形成；建立 | 品牌口号或引用原文 |
| 证据类型 | 验证方法；试验方式；研究依据 | 确需按证据来源进行分类时 |
| 验证层级 | 验证阶段；试验层次；直接写明具体方法或环境 | 确需表达由部件到系统的分级关系时 |
| 失效与恢复 | 直接写明中断、重连、失锁重捕获或重新同步等具体过程 | 器件失效机理、故障恢复时间或可靠性指标中的正式术语 |
| 低频辅助初始化 | 低频辅助信息；另句写明时间基准、候选时隙或初始指向等具体内容 | 已定义了明确初始化流程时 |
| 信道与波束状态诊断 | 直接写明信道衰减、波束指向偏差及其判别结果 | 已定义诊断对象、输入、输出和判据时 |
| 退化 | 性能下降；或直接写明信道衰减、波束偏离、温升引起的功率限制等具体原因 | 已明确定义的退化模型、退化状态或器件退化机理 |
| 波束失配 | 波束指向偏差；或直接写明主波束偏离链路视线方向 | 明确定义收发波束、波束与信道或码字之间的失配关系时 |
| 业务速率失配 | 传输参数调整滞后于信道变化 | 已定义目标业务速率、可用传输速率及其失配量时 |
| 置信约束 | 可靠性约束；或直接写明置信区间、置信水平和概率条件 | 已建立明确的置信度约束或机会约束数学模型时 |
| 选档 | 传输档位选择；传输档位判定 | 图中文字空间有限，且正文已经给出完整定义时 |
| 跟踪状态转换 | 跟瞄策略调整；或直接写明波束展宽、局部搜索、失锁重捕获等动作 | 已建立正式状态机并定义状态转移条件时 |
| 状态龄期 | 状态测量至控制生效时延；或直接写明测量、可用和生效时刻 | 正式研究信息年龄或 Age of Information 时 |
| 预测角域 | 角度不确定范围 | 已对角域给出明确数学定义时 |
| 两级选型 | 综合比较与方案确定 | 已明确划分两个选型阶段及各阶段判据时 |
| 有限重传 | 重传控制；直接写明最大重传次数 | 引用正式标准或已定义有限重传策略时 |
| 方法输出与仿真验证 | 仿真验证；具体结果及用途写入正文 | 章节确实同时定义交付物和验证过程时 |
| 组织……资源 | 根据具体动作写成配置、分配或调度时频、带宽、功率、计算等资源 | “资源组织方式”作为总体方案名称时可以保留 |
| 贯通……过程 | 写成实现……功能、完成……流程、建立……链路，或直接说明各阶段动作 | 确实强调多个独立环节形成端到端链路时，可以使用“贯通全链路” |
| 英文缩略语首次出现时不作说明 | 在课题正文首次出现时写“中文全称（缩略语）”，后文直接使用缩略语 | 型号、单位、公式变量、接口标号，以及没有通行中文全称的专名 |
| 离线仿真软件 | 浮点参考模型；仿真程序；直接写明实际输出物 | 确为正式软件交付物且有明确名称时 |
| “输入：A｜B｜C”式资料罗列 | 直接写明资料名称，用顿号、逗号或“和”自然连接；关系由位置和箭头表达 | 信号流图中标注真实输入端口或接口时 |
| 多源异步状态与观测；多源异步输入 | 直接列出实际信息，如GNSS/INS与任务轨迹、四路相干中频、窄带导引与信号质量、地面站坐标与安装关系、TDD状态，并分别接入对应处理环节 | 研究对象确为异步多源融合，且正文已定义各来源、时间戳、更新周期和配准方法时 |
| 研究内容中使用“应包含；应与……匹配；应明确”等要求式表述 | 直接说明研究对象、参数关系和实施动作，如“输入数据包括……”“统一……参数”“核对……” | 技术标准、接口规范、考核要求、约束条件或引用原文 |
| 标准测试向量；典型工况；边界工况；信道工况 | 直接写明实际数据或变化条件，如发送比特序列、接收采样数据、各处理环节参考结果、器件实测数据、路径损耗、接收功率、频率选择性或多普勒 | 引用明确标准，或已将多项参数组合定义为具体试验工况或场景时 |
| 不作为……前提/条件；技术储备；工程主线；后续评估；进入条件；并非/不是……而是 | 直接陈述研制任务、形成能力、适配对象或真实限制 | 真实限制、风险提示、合规要求，或必须纠正误解的技术对比 |
| 拉距试验 | 描述通信距离验证时用“通信距离测试”，可按对象写“机载通信距离测试”；描述室外试验环境时用“外场试验”，二者不作无条件互换 | 引用原始报告、标准或正式试验名称时保留原称；不作为所有工程场景中的禁用词 |
